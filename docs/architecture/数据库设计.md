# 数据库设计文档

## 1. 数据库概述

### 1.1 设计原则

1. **规范化设计**：遵循数据库三大范式，避免数据冗余
2. **性能优化**：合理使用索引，优化查询性能
3. **扩展性**：设计考虑未来扩展，支持水平分库分表
4. **安全性**：敏感数据加密存储，权限控制
5. **审计追踪**：完整的数据变更记录

### 1.2 命名规范

| 对象 | 命名规则 | 示例 |
|------|---------|------|
| **数据库** | `xingran_next` | - |
| **表名** | `模块_功能` | `sys_user`, `sys_role` |
| **字段名** | `小写+下划线` | `user_name`, `create_time` |
| **索引名** | `idx_表名_字段` | `idx_sys_user_username` |
| **外键名** | `fk_子表_父表` | `fk_user_role_role` |
| **主键** | `id` (UUID) | - |

### 1.3 字段规范

| 字段类型 | 说明 | 示例 |
|---------|------|------|
| **主键** | `UUID` | `id` |
| **创建时间** | `timestamp` | `create_time` |
| **更新时间** | `timestamp` | `update_time` |
| **删除标记** | `boolean` | `del_flag` |
| **创建者** | `varchar(64)` | `create_by` |
| **更新者** | `varchar(64)` | `update_by` |
| **版本号** | `int` | `version` |
| **备注** | `text` | `remark` |

## 2. 数据库选型

### 2.1 PostgreSQL 18.1+ 选择理由

| 特性 | PostgreSQL 18.1+ | MySQL 8.0 | 优势方 |
|------|------------------|-----------|--------|
| **ACID支持** | 完全支持 | 完全支持 | 平手 |
| **JSON支持** | 原生支持，性能优化 | 有限支持 | PostgreSQL |
| **全文检索** | 内置，多语言支持 | 需要插件 | PostgreSQL |
| **窗口函数** | 支持，功能强大 | 支持 | PostgreSQL |
| **并发控制** | MVCC，性能优化 | MVCC | PostgreSQL |
| **扩展性** | 丰富插件生态 | 有限插件 | PostgreSQL |
| **数据类型** | 极其丰富 | 标准 | PostgreSQL |
| **性能** | I/O优化，3倍性能提升 | 简单查询优秀 | PostgreSQL |
| **版本升级** | 兼容性改进 | 升级复杂 | PostgreSQL |

### 2.2 配置优化

## 3. 状态值统一规范

### 3.1 通用规则

为保持系统一致性，所有模块的状态字段必须遵循以下统一规则：

- **0 = 启用/正常/显示/有效**：表示该数据处于活跃可用状态
- **1 = 禁用/停用/隐藏/无效**：表示该数据处于不可用状态

### 3.2 各模块状态定义

| 模块 | 字段名 | 类型 | 0值含义 | 1值含义 | Go类型 | TypeScript类型 |
|------|--------|------|--------|--------|--------|----------------|
| **用户** | status | UserStatus | 启用 | 禁用 | `UserStatus` | `0 \| 1` |
| **角色** | status | RoleStatus | 正常 | 停用 | `RoleStatus` | `0 \| 1` |
| **菜单** | status | MenuStatus | 正常 | 停用 | `MenuStatus` | `0 \| 1` |
| **部门** | status | DeptStatus | 正常 | 停用 | `DeptStatus` | `0 \| 1` |
| **岗位** | status | PostStatus | 正常 | 停用 | `PostStatus` | `0 \| 1` |

### 3.3 Go后端状态定义

```go
// 用户状态
type UserStatus int
const (
    UserStatusEnabled  UserStatus = 0 // 启用
    UserStatusDisabled UserStatus = 1 // 禁用
)

// 角色状态
type RoleStatus int
const (
    RoleStatusEnabled  RoleStatus = 0 // 正常
    RoleStatusDisabled RoleStatus = 1 // 停用
)

// 菜单状态
type MenuStatus int
const (
    MenuStatusShow MenuStatus = 0 // 显示
    MenuStatusHide MenuStatus = 1 // 隐藏
)

// 部门状态
type DeptStatus int
const (
    DeptStatusNormal DeptStatus = 0 // 正常
    DeptStatusStop   DeptStatus = 1 // 停用
)

// 岗位状态
type PostStatus int
const (
    PostStatusNormal PostStatus = 0 // 正常
    PostStatusStop   PostStatus = 1 // 停用
)
```

### 3.4 TypeScript前端状态定义

```typescript
// 用户状态
export type UserStatus = 0 | 1;  // 0:启用 1:禁用

// 角色状态
export type RoleStatus = 0 | 1;  // 0:正常 1:停用

// 菜单状态（菜单本身的启用/停用，与可见性是两个独立字段）
export type MenuStatus = 0 | 1;  // 0:正常 1:停用

// 菜单可见性（布尔语义，与状态字段语义相反）
export type VisibleType = 0 | 1;  // 0:隐藏 1:显示

// 部门状态
export type DeptStatus = 0 | 1;  // 0:正常 1:停用

// 岗位状态
export type PostStatus = 0 | 1;  // 0:正常 1:停用
```

### 3.5 前端状态显示组件

```typescript
// 统一状态显示Tag组件
const getStatusTag = (status: number, type: 'user' | 'role' | 'menu' | 'dept' | 'post') => {
  const config = {
    user: { enabled: '启用', disabled: '禁用' },
    role: { enabled: '正常', disabled: '停用' },
    menu: { enabled: '显示', disabled: '隐藏' },
    dept: { enabled: '正常', disabled: '停用' },

    <Tag color={status === 0 ? 'success' : 'error'}>
      {status === 0 ? config[type].enabled : config[type].disabled}
    </Tag>
  );
};
```

```go
// VERIFY: 实际包名为 models（非 model），基础结构体为 BaseModel（非 BaseEntity），且 BaseModel 不含 Remark 字段（仅 ID/CreatedAt/UpdatedAt/DeletedAt/CreatedBy/UpdatedBy/Version）
package models

import (
    "time"
    "github.com/google/uuid"
    "gorm.io/gorm"
)

// BaseModel 基础模型
type BaseModel struct {
    ID        string         `gorm:"type:uuid;primary_key" json:"id"`
    CreatedAt time.Time      `json:"createdAt"`
    UpdatedAt time.Time      `json:"updatedAt"`
    DeletedAt gorm.DeletedAt `gorm:"index" json:"deletedAt,omitempty"`
    CreatedBy string         `gorm:"size:64" json:"createdBy"`
    UpdatedBy string         `gorm:"size:64" json:"updatedBy"`
    Version   int            `json:"version"`
}

// BeforeCreate GORM钩子 - 创建前
func (b *BaseModel) BeforeCreate(tx *gorm.DB) error {
    if b.ID == "" {
        b.ID = uuid.New().String()
    }
    return nil
}
```
