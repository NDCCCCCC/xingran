# 时间工具函数使用说明

## 概述

为了统一项目中所有时间显示的格式，已创建统一的时间格式化工具函数。所有页面组件应使用此工具函数，确保时间显示的一致性。

## 工具函数位置

**文件路径**: `xingran-react-frontend/src/utils/datetime.ts`

## 可用函数

### `formatDateTime(date, format?)`

统一时间格式化函数，默认格式为 `YYYY-MM-DD HH:mm:ss`。

**参数**:
- `date`: 日期字符串、Date对象或null/undefined
- `format`: 可选的格式字符串，默认 `'YYYY-MM-DD HH:mm:ss'`

**返回值**: 格式化后的时间字符串，空值返回 `'-'`

**示例**:
```typescript
import { formatDateTime } from '@/utils/datetime';

// 默认格式: YYYY-MM-DD HH:mm:ss
formatDateTime('2025-01-17T14:30:45Z');
// 返回: '2025-01-17 14:30:45'

// 自定义格式
formatDateTime('2025-01-17T14:30:45Z', 'YYYY-MM-DD HH:mm');
// 返回: '2025-01-17 14:30'

formatDateTime('2025-01-17T14:30:45Z', 'MM-DD');
// 返回: '01-17'

// 空值处理
formatDateTime(null);
// 返回: '-'
```

### `formatDate(date)`

格式化日期（不含时间），格式为 `YYYY-MM-DD`。

**参数**:
- `date`: 日期字符串、Date对象或null/undefined

**返回值**: 格式化后的日期字符串

**示例**:
```typescript
import { formatDate } from '@/utils/datetime';

formatDate('2025-01-17T14:30:45Z');
// 返回: '2025-01-17'
```

### `formatTime(date)`

格式化时间（不含日期），格式为 `HH:mm:ss`。

**参数**:
- `date`: 日期字符串、Date对象或null/undefined

**返回值**: 格式化后的时间字符串

**示例**:
```typescript
import { formatTime } from '@/utils/datetime';

formatTime('2025-01-17T14:30:45Z');
// 返回: '14:30:45'
```

## 使用场景

### 表格列渲染

```typescript
import { formatDateTime } from '@/utils/datetime';

const columns: ColumnsType<DataType> = [
  {
    title: '创建时间',
    dataIndex: 'createdAt',
    key: 'createdAt',
    render: (date: string) => formatDateTime(date),
  },
  {
    title: '更新时间',
    dataIndex: 'updatedAt',
    key: 'updatedAt',
    render: (date: string) => formatDateTime(date, 'YYYY-MM-DD HH:mm'),
  },
];
```

### 详情显示

```typescript
import { formatDateTime } from '@/utils/datetime';

<Descriptions>
  <Descriptions.Item label="创建时间">
    {formatDateTime(record.createdAt)}
  </Descriptions.Item>
  <Descriptions.Item label="更新时间">
    {formatDateTime(record.updatedAt, 'YYYY-MM-DD HH:mm')}
  </Descriptions.Item>
</Descriptions>
```

### 工具函数中重新导出

如果需要在其他工具模块中使用，可以重新导出：

```typescript
// utils/someModule.ts
export { formatDateTime, formatDate, formatTime } from '@/utils/datetime';
```

## 重要说明

### 时区处理

后端存储的是本地时间（Asia/Shanghai），但 JSON 序列化时可能带 Z 后缀。工具函数已自动处理此问题，会去除 Z 后缀后进行格式化。

```typescript
// 后端返回: "2025-01-17T14:30:45Z"
// 实际存储: Asia/Shanghai 时区的 2025-01-17 14:30:45
formatDateTime('2025-01-17T14:30:45Z');
// 正确返回: '2025-01-17 14:30:45'
```

### 禁止使用的方法

❌ **不要直接使用 `dayjs().format()`**
```typescript
// 错误
import dayjs from 'dayjs';
dayjs(date).format('YYYY-MM-DD HH:mm:ss');

// 正确
import { formatDateTime } from '@/utils/datetime';
formatDateTime(date);
```

❌ **不要使用 `toLocaleString()`**
```typescript
// 错误
new Date(date).toLocaleString();
new Date(date).toLocaleDateString();

// 正确
import { formatDateTime } from '@/utils/datetime';
formatDateTime(date);
```

❌ **不要在组件中定义本地格式化函数**
```typescript
// 错误
const formatTime = (date: string) => {
  return new Date(date).toLocaleString();
};

// 正确
import { formatDateTime } from '@/utils/datetime';
```

### 特殊场景

#### 相对时间显示

如需显示相对时间（如"5分钟前"），可以使用 dayjs 的 `fromNow()` 功能：

```typescript
import dayjs from 'dayjs';
import relativeTime from 'dayjs/plugin/relativeTime';
import 'dayjs/locale/zh-cn';
import { formatDateTime } from '@/utils/datetime';

dayjs.extend(relativeTime);
dayjs.locale('zh-cn');

// 相对时间显示
<Tooltip title={formatDateTime(time)}>
  <span>{dayjs(time).fromNow()}</span>
</Tooltip>
```

#### Cron 表达式选择器

CronSelector 组件使用的时间格式化函数是特定于 Cron 表达式的，应保留在组件内部。

## 迁移指南

### 从旧代码迁移

如果你有使用 `dayjs().format()` 或 `toLocaleString()` 的代码，请按以下步骤迁移：

1. **添加导入**:
   ```typescript
   import { formatDateTime } from '@/utils/datetime';
   ```

2. **替换函数调用**:
   ```typescript
   // 旧代码
   dayjs(date).format('YYYY-MM-DD HH:mm:ss')
   new Date(date).toLocaleString()

   // 新代码
   formatDateTime(date)
   ```

3. **删除旧的 dayjs 导入** (如果没有其他用途):
   ```typescript
   // 删除
   import dayjs from 'dayjs';
   ```

### 从本地格式化函数迁移

如果你在组件或工具模块中定义了本地的格式化函数：

1. **删除本地函数定义**
2. **添加从 `@/utils/datetime` 的导入**
3. **更新函数调用**

## 格式化字符串参考

| 格式 | 输出示例 | 说明 |
|------|----------|------|
| `YYYY-MM-DD HH:mm:ss` | `2025-01-17 14:30:45` | 完整日期时间（默认） |
| `YYYY-MM-DD HH:mm` | `2025-01-17 14:30` | 日期时间（不含秒） |
| `YYYY-MM-DD` | `2025-01-17` | 仅日期 |
| `MM-DD` | `01-17` | 月-日 |
| `HH:mm:ss` | `14:30:45` | 仅时间 |
| `HH:mm` | `14:30` | 时间（不含秒） |

## 常见问题

### Q: 为什么要统一时间格式化？

A: 统一时间格式化有以下好处：
1. **一致性**: 整个应用的时间显示格式统一
2. **可维护性**: 只需在一个地方修改时间格式
3. **时区处理**: 统一处理后端返回的时间格式问题
4. **减少代码**: 避免重复定义格式化函数

### Q: 默认格式为什么是 `YYYY-MM-DD HH:mm:ss`？

A: 这是最常用的时间显示格式，包含年月日和时分秒，适合大多数场景。如需其他格式，可通过第二个参数指定。

### Q: 空值如何处理？

A: 所有函数对 `null`、`undefined` 或空字符串都会返回 `'-'`，无需额外处理。

### Q: 如何处理不同时区的时间？

A: 工具函数已处理后端返回的时间带 Z 后缀的情况。如果需要处理其他时区，请使用 dayjs 的时区插件。
