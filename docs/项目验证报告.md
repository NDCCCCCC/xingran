## API响应规范验证

### 响应格式：✅ 符合

```typescript
interface ApiResponse<T> {
    code: number;      // 0 = 成功, 非0 = 失败
    message: string;   // 响应消息
    data: T;          // 响应数据
}
```

### 前端拦截器配置：✅ 正确

```typescript
// ruoyi-react-frontend/src/lib/api.ts
api.interceptors.response.use(
    (response: AxiosResponse) => {
        const { data } = response;
        // code === 0 表示成功
        if (data.code === 0) {
            return data;
        } else {
            message.error(data.message || '请求失败');
            return Promise.reject(new Error(data.message));
        }
    }
);
```

### HTTP状态码处理

| HTTP状态 | 处理方式 |
|----------|----------|
| 200 | 正常响应，检查业务状态码 |
| 400 | 提示错误消息 |
| 401 | 清除token，跳转登录 |
| 403 | 提示权限不足 |
| 404 | 提示资源不存在 |
| 500 | 提示服务器错误 |
