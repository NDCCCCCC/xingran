## 二、文件上传服务

### 2.1 文件分类配置

系统支持以下文件分类，每个分类有独立的验证规则：

| 分类 | 最大大小 | 允许扩展名 | 提取尺寸 | 说明 |
|------|----------|-----------|----------|------|
| `avatar` | 2MB | .jpg, .jpeg, .png | ✓ | 用户头像 |
| `room-photo` | 5MB | .jpg, .jpeg, .png | ✓ | 机房照片 |
| `image` | 5MB | .jpg, .jpeg, .png, .gif, .webp | ✓ | 通用图片 |
| `document` | 10MB | .pdf, .doc, .docx, .xlsx, .txt | ✗ | 通用文档 |
| `import` | 10MB | .xlsx, .xls | ✗ | 导入文件 |
| `export` | 10MB | .xlsx, .pdf | ✗ | 导出文件 |

### 2.2 文件上传流程

```
用户上传文件
    │
    ▼
1. 前端验证（文件大小、类型）
    │
    ▼
2. 上传到后端 API
    │
    ▼
3. 后端验证（使用分类配置）
    │
    ▼
4. 计算文件哈希（SHA256）
    │
    ▼
5. 检查去重（相同哈希返回已有文件）
    │
    ▼
6. 保存文件到磁盘
    │
    ▼
7. 提取图片尺寸（如配置允许）
    │
    ▼
8. 创建数据库记录
    │
    ▼
9. 记录访问日志
    │
    ▼
10. 返回文件信息（含width/height/metadata）
```

### 2.3 数据库模型

**sys_files表结构：**

```sql
CREATE TABLE sys_files (
    id              UUID PRIMARY KEY,
    file_name       VARCHAR(255)      -- 原始文件名
    file_size       BIGINT            -- 文件大小（字节）
    file_type       VARCHAR(100)      -- MIME类型
    extension       VARCHAR(50)       -- 文件扩展名
    storage_path    VARCHAR(500)      -- 存储路径
    file_hash       VARCHAR(64)       -- SHA256哈希
    uploader_id     UUID              -- 上传者ID
    business_type   VARCHAR(50)       -- 业务类型
    is_deleted      BOOLEAN           -- 软删除标记
    delete_time     TIMESTAMP         -- 删除时间
    file_width      INT               -- 图片宽度（新增）
    file_height     INT               -- 图片高度（新增）
    metadata        JSONB             -- 扩展元数据（新增）
    created_at      TIMESTAMP
    updated_at      TIMESTAMP
);
```

### 2.4 API响应格式

**上传文件响应：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": "uuid-string",
    "fileName": "example.jpg",
    "fileSize": 102400,
    "fileType": "image/jpeg",
    "extension": ".jpg",
    "url": "/uploads/avatar/abc123_1234567890.jpg",
    "width": 1920,
    "height": 1080,
    "metadata": "{\"width\":1920,\"height\":1080}",
    "createdAt": "2026-01-16T10:30:00Z"
  }
}
```

## 三、Excel导入导出功能

### 3.1 实现方式对比

| 模块 | 实现方式 | 原因 |
|------|----------|------|
| 运维管理模块 | 后端excelize服务 | 数据量大、需要复杂验证 |
| 节假日管理 | 前端XLSX处理 | 简单数据、用户体验优先 |
| 用户管理 | TODO | 待实现 |

### 3.2 后端Excel服务（运维模块）

**支持的实体：**
- building（楼宇）
- floor（楼层）
- workstation（工位）
- serverRoom（机房）
- roomDevice（机房设备）
- dedicatedLine（专线）
- infoPoint（信息点）

**配置文件：** `internal/services/operations/excel_config.go`

**API端点：**
- `GET /ops/{entity}/template` - 下载Excel模板
- `POST /ops/{entity}/import` - 导入Excel数据
- `GET /ops/{entity}/export` - 导出Excel数据

### 3.3 前端Excel处理（节假日模块）

**组件：** `ExcelImport.tsx` + `excelUtils.ts`

**特点：**
- 前端直接解析Excel文件
- 即时预览和验证
- 无需等待服务器响应

## 四、前端组件使用

### 4.1 FileUpload组件

**基础用法：**

```tsx
import FileUpload, { type FileUploadResponse } from '@/components/shared/FileUpload';

<FileUpload
  category="room-photo"
  accept="image/*"
  maxSize={5 * 1024 * 1024}
  maxCount={1}
  listType="picture-card"
  onUploadSuccess={(file, response) => {
    console.log('上传成功:', response.width, 'x', response.height);
  }}
/>
```

**属性说明：**

| 属性 | 类型 | 说明 |
|------|------|------|
| category | string | 文件分类，决定验证规则 |
| accept | string | 接受的文件类型 |
| maxSize | number | 最大文件大小（字节） |
| maxCount | number | 最大文件数量 |
| listType | string | 列表显示样式 |
| onUploadSuccess | function | 上传成功回调 |
| onUploadError | function | 上传失败回调 |

### 4.2 ExcelImport组件

**基础用法：**

```tsx
import ExcelImport from '@/components/shared/ExcelImport';

<ExcelImport
  entityType="building"
  entityName="楼宇"
  templateUrl="/ops/building/template"
  importUrl="/ops/building/import"
  onImportSuccess={() => {
    message.success('导入成功');
    refetch();
  }}
  visible={importModalVisible}
  onClose={() => setImportModalVisible(false)}
/>
```

## 五、特殊实现

**文件：** `internal/core/captcha_background.go`

**特点：**
- 独立实现，不使用通用文件服务

- 无需后端参与

## 六、文件存储策略

### 6.1 当前实现

- **存储位置：** 本地磁盘 `./uploads/` 目录
- **目录结构：** `{category}/{filename}`
- **命名规则：** `{uuid_prefix}_{timestamp}{ext}`

### 6.2 未来优化方向

1. **异步上传：** 大文件使用分片上传 + 进度推送
2. **云存储：** 支持OSS/S3等对象存储
3. **CDN加速：** 静态资源CDN分发
4. **导入历史：** 记录Excel导入历史，支持回滚

## 七、安全考虑

### 7.1 文件验证

- **扩展名白名单：** 只允许配置的扩展名
- **文件大小限制：** 按分类设置不同限制
- **MIME类型检查：** 验证Content-Type
- **文件内容检查：** 图片尺寸提取验证

### 7.2 访问控制

- **认证要求：** 所有上传下载接口需要认证
- **权限控制：** 基于业务类型的访问权限
- **审计日志：** 记录所有文件操作

## 十一、FAQ

**Q: 为什么节假日管理保持前端Excel处理？**
A: 节假日数据量小，前端处理更快速且用户体验更好。

**Q: 如何添加新的文件分类？**
A: 在 `CategoryConfigs` 中添加新配置即可。

**Q: 图片尺寸提取支持哪些格式？**
A: 目前支持 JPG、PNG、GIF、WEBP、BMP。

**Q: 元数据字段可以存储什么？**
A: JSON格式，可存储图片尺寸、EXIF信息等任意扩展数据。
