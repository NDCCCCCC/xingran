# 数据库设计文档

## 1. 数据库概述

### 1.1 设计原则

1. **规范化设计**：遵循数据库三大范式，避免数据冗余
2. **性能优化**：合理使用索引，优化查询性能
3. **扩展性**：设计考虑未来扩展，支持水平分库分表
4. **安全性**：敏感数据加密存储，权限控制
5. **审计追踪**：完整的数据变更记录

### 1.2 命名规范

| 对象 | 命名规则 | 示例 |
|------|---------|------|
| **数据库** | `ruoyi_next` | - |
| **表名** | `模块_功能` | `sys_user`, `sys_role` |
| **字段名** | `小写+下划线` | `user_name`, `create_time` |
| **索引名** | `idx_表名_字段` | `idx_sys_user_username` |
| **外键名** | `fk_子表_父表` | `fk_user_role_role` |
| **主键** | `id` (UUID) | - |

### 1.3 字段规范

| 字段类型 | 说明 | 示例 |
|---------|------|------|
| **主键** | `UUID` | `id` |
| **创建时间** | `timestamp` | `create_time` |
| **更新时间** | `timestamp` | `update_time` |
| **删除标记** | `boolean` | `del_flag` |
| **创建者** | `varchar(64)` | `create_by` |
| **更新者** | `varchar(64)` | `update_by` |
| **版本号** | `int` | `version` |
| **备注** | `text` | `remark` |

## 2. 数据库选型

### 2.1 PostgreSQL 18.1+ 选择理由

| 特性 | PostgreSQL 18.1+ | MySQL 8.0 | 优势方 |
|------|------------------|-----------|--------|
| **ACID支持** | 完全支持 | 完全支持 | 平手 |
| **JSON支持** | 原生支持，性能优化 | 有限支持 | PostgreSQL |
| **全文检索** | 内置，多语言支持 | 需要插件 | PostgreSQL |
| **窗口函数** | 支持，功能强大 | 支持 | PostgreSQL |
| **并发控制** | MVCC，性能优化 | MVCC | PostgreSQL |
| **扩展性** | 丰富插件生态 | 有限插件 | PostgreSQL |
| **数据类型** | 极其丰富 | 标准 | PostgreSQL |
| **性能** | I/O优化，3倍性能提升 | 简单查询优秀 | PostgreSQL |
| **版本升级** | 兼容性改进 | 升级复杂 | PostgreSQL |

### 2.2 技术特性

#### 2.2.1 核心优势
- **高性能I/O子系统**：相比前版本性能提升3倍
- **新增索引类型**：BRIN、GIN优化，提升查询性能
- **并发性能优化**：改进的锁机制和并行查询
- **JSON支持增强**：更快的JSON处理和查询
- **分区表优化**：更好的分区裁剪和查询优化

#### 2.2.2 部署配置
- **版本选择**：PostgreSQL 18.1+
- **字符集**：UTF8
- **时区**：UTC
- **连接池**：最大连接数100，空闲连接10
- **事务隔离级别**：READ COMMITTED
| **社区** | 活跃 | 最广泛 | MySQL |

### 2.2 配置优化

```sql
-- postgresql.conf 关键配置
-- 内存配置
shared_buffers = 256MB                 # 共享缓冲区
effective_cache_size = 1GB              # 有效缓存大小
work_mem = 4MB                          # 工作内存
maintenance_work_mem = 64MB             # 维护工作内存

-- 连接配置
max_connections = 200                   # 最大连接数
superuser_reserved_connections = 3     # 超级用户保留连接

-- WAL配置
wal_buffers = 16MB                      # WAL缓冲区
checkpoint_completion_target = 0.9      # 检查点完成目标
wal_writer_delay = 200ms               # WAL写入延迟

-- 查询优化
random_page_cost = 1.1                 # 随机页面成本
effective_io_concurrency = 200         # 有效IO并发

-- 日志配置
log_min_duration_statement = 1000       # 记录慢查询
log_checkpoints = on                    # 记录检查点
log_connections = on                   # 记录连接
log_disconnections = on                # 记录断开连接
log_lock_waits = on                    # 记录锁等待
```

## 3. 数据库表设计

### 3.1 用户管理模块

#### 3.1.1 用户表（sys_user）

```sql
CREATE TABLE sys_user (
    id                 UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username           VARCHAR(50) NOT NULL UNIQUE,
    password           VARCHAR(128) NOT NULL,
    salt               VARCHAR(64) NOT NULL,
    nickname           VARCHAR(50),
    email              VARCHAR(100),
    phone              VARCHAR(20),
    avatar             VARCHAR(255),
    gender             SMALLINT DEFAULT 0 CHECK (gender IN (0,1,2)), -- 0:未知 1:男 2:女
    dept_id            UUID,
    status             SMALLINT DEFAULT 1 CHECK (status IN (0,1)),   -- 0:禁用 1:启用
    login_ip           VARCHAR(50),
    login_time         TIMESTAMP,
    pwd_update_time    TIMESTAMP,
    pwd_expire_days    SMALLINT DEFAULT 90,
    init_flag          SMALLINT DEFAULT 0 CHECK (init_flag IN (0,1)), -- 0:未初始化 1:已初始化
    create_by          VARCHAR(64),
    create_time        TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_by          VARCHAR(64),
    update_time        TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    del_flag           BOOLEAN DEFAULT FALSE,
    version            INTEGER DEFAULT 1,
    remark             TEXT
);

-- 索引
CREATE INDEX idx_sys_user_username ON sys_user(username);
CREATE INDEX idx_sys_user_dept_id ON sys_user(dept_id);
CREATE INDEX idx_sys_user_status ON sys_user(status);
CREATE INDEX idx_sys_user_email ON sys_user(email);
CREATE INDEX idx_sys_user_create_time ON sys_user(create_time);
```

CREATE TABLE sys_oper_log_202401 PARTITION OF sys_oper_log
    FOR VALUES FROM ('2024-01-01') TO ('2024-02-01');

CREATE TABLE sys_oper_log_202402 PARTITION OF sys_oper_log
    FOR VALUES FROM ('2024-02-01') TO ('2024-03-01');

-- 自动创建分区的函数
CREATE OR REPLACE FUNCTION create_monthly_partition()
RETURNS void AS $$
DECLARE
    start_date DATE;
    end_date DATE;
    partition_name TEXT;
BEGIN
    -- 创建未来3个月的分区
    FOR i IN 0..3 LOOP
        start_date := date_trunc('month', CURRENT_DATE + INTERVAL '1 month' * i);
        end_date := start_date + INTERVAL '1 month';
        partition_name := 'sys_oper_log_' || to_char(start_date, 'YYYYMM');

        EXECUTE format('CREATE TABLE IF NOT EXISTS %I PARTITION OF sys_oper_log
                        FOR VALUES FROM (%L) TO (%L)',
                       partition_name, start_date, end_date);
    END LOOP;

    -- 删除3年前的分区
    FOR r IN
        SELECT tablename
        FROM pg_tables
        WHERE schemaname = 'public'
        AND tablename LIKE 'sys_oper_log_%'
        AND tablename < 'sys_oper_log_' || to_char(CURRENT_DATE - INTERVAL '3 year', 'YYYYMM')
    LOOP
        EXECUTE 'DROP TABLE IF EXISTS ' || r.tablename;
    END LOOP;
END;
$$ LANGUAGE plpgsql;

-- 创建定时任务执行分区管理

CREATE TABLE sys_audit_log (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    table_name  VARCHAR(50) NOT NULL,
    operation   VARCHAR(10) NOT NULL, -- INSERT, UPDATE, DELETE
    old_values  JSONB,
    new_values  JSONB,

    user_name   VARCHAR(50),
    ipaddr      VARCHAR(128),

CREATE OR REPLACE FUNCTION audit_trigger()
RETURNS TRIGGER AS $$
BEGIN
    IF TG_OP = 'DELETE' THEN
        INSERT INTO sys_audit_log (table_name, operation, old_values)
        VALUES (TG_TABLE_NAME, TG_OP, to_jsonb(OLD));
        RETURN OLD;
    ELSIF TG_OP = 'UPDATE' THEN
        INSERT INTO sys_audit_log (table_name, operation, old_values, new_values)
        VALUES (TG_TABLE_NAME, TG_OP, to_jsonb(OLD), to_jsonb(NEW));
        RETURN NEW;
    ELSIF TG_OP = 'INSERT' THEN
        INSERT INTO sys_audit_log (table_name, operation, new_values)
        VALUES (TG_TABLE_NAME, TG_OP, to_jsonb(NEW));
        RETURN NEW;
    END IF;
    RETURN NULL;
END;
$$ LANGUAGE plpgsql;

-- 为重要表创建审计触发器
CREATE TRIGGER tr_audit_sys_user
    AFTER INSERT OR UPDATE OR DELETE ON sys_user
    FOR EACH ROW
    EXECUTE FUNCTION audit_trigger();

CREATE OR REPLACE FUNCTION init_user(
    p_username VARCHAR(50),
    p_password VARCHAR(128),
    p_nickname VARCHAR(50),
    p_email VARCHAR(100),
    p_dept_id UUID DEFAULT NULL

    v_user_id UUID;
    v_salt VARCHAR(64);
    v_hashed_password VARCHAR(128);

    v_salt := encode(gen_random_bytes(32), 'hex');

    v_hashed_password := crypt(p_password, v_salt);

    INSERT INTO sys_user (
        username,
        password,
        salt,
        nickname,
        email,
        dept_id,
        status,
        init_flag,
        pwd_update_time
    ) VALUES (
        p_username,
        v_hashed_password,
        v_salt,
        p_nickname,
        p_email,
        p_dept_id,
        1,
        1,
        CURRENT_TIMESTAMP
    ) RETURNING id INTO v_user_id;

    -- 记录操作日志

        business_type,

        oper_time,
        status
    ) VALUES (

CREATE OR REPLACE FUNCTION batch_delete_users(
    p_user_ids UUID[],
    p_operator VARCHAR(50)
) RETURNS INTEGER AS $$
DECLARE
    v_count INTEGER := 0;
    v_user RECORD;
BEGIN
    -- 记录删除前的信息
    FOR v_user IN SELECT id, username FROM sys_user WHERE id = ANY(p_user_ids) AND del_flag = FALSE
    LOOP
        -- 软删除用户
        UPDATE sys_user
        SET del_flag = TRUE,
            update_by = p_operator,
            update_time = CURRENT_TIMESTAMP
        WHERE id = v_user.id;

        v_count := v_count + 1;

        -- 记录日志
        INSERT INTO sys_oper_log (
            title,
            business_type,
            method,
            operator_name,
            oper_param,
            oper_time,
            status
        ) VALUES (
            '批量删除用户',
            3,
            'batch_delete_users',
            p_operator,
            json_build_object('username', v_user.username, 'id', v_user.id)::text,
            CURRENT_TIMESTAMP,
            0
        );
    END LOOP;

    RETURN v_count;
END;

if [ $# -ne 1 ]; then
    echo "Usage: $0 <backup_file>"
    exit 1

BACKUP_FILE=$1
DB_NAME="ruoyi_next"
DB_USER="postgres"

# 停止应用服务
systemctl stop ruoyi-next

# 删除现有数据库
dropdb -h localhost -U $DB_USER $DB_NAME

createdb -h localhost -U $DB_USER $DB_NAME

echo "Database restore completed: $BACKUP_FILE"
