## 当前架构（System 模块）

**架构特点**：
- 缓存服务位于 `internal/services/system/` 模块
- 通过 `CacheProvider` 接口实现依赖倒置
- 服务组合模式，避免代码重复
- 统一的缓存配置和工具函数

**文件结构**：
```
internal/services/system/
├── cache_provider.go           # CacheProvider 接口
├── cache_utils.go              # 缓存工具函数
├── role_service.go             # 角色基础服务
├── role_cache_impl.go          # 带缓存的角色服务
├── post_service.go             # 岗位基础服务
├── post_cache_impl.go          # 带缓存的岗位服务
├── dict_type_service.go        # 字典类型基础服务
├── dict_cache_impl.go          # 带缓存的字典服务
├── department_service.go       # 部门基础服务
├── department_cache_impl.go    # 带缓存的部门服务
├── menu_service.go             # 菜单基础服务
└── menu_cache_impl.go          # 带缓存的菜单服务
```

## 架构特点

### CacheProvider 接口

**位置**：`internal/services/system/cache_provider.go`

```go
type CacheProvider interface {
    GetOrSet(
        ctx context.Context,
        key string,
        dest interface{},
        expiration time.Duration,
        query func() (interface{}, error),
    ) error

    Delete(ctx context.Context, key string) error
    DeleteByPattern(ctx context.Context, pattern string) error
}

// NoOpCacheProvider 空实现（用于测试）
type NoOpCacheProvider struct{}
```

### 缓存服务基类

**位置**：`internal/services/system/cache_utils.go`

```go
type CacheServiceBase struct {
    Config *services.CacheConfigService
}

func (b *CacheServiceBase) GetExpiration(configKey string, defaultVal time.Duration) time.Duration

func InvalidateCacheByPattern(ctx, cache CacheProvider, patterns []string, module string)
func InvalidateCacheByKey(ctx, cache CacheProvider, keys []string, module string)
```

### 创建带缓存的服务

```go
// 1. 路由中创建 CacheProvider 适配器
cacheProvider := NewDataCacheAdapter(core.DataCacheService)

// 2. 创建带缓存的服务
roleService := system.NewRoleServiceWithCache(
    core.DB.GetDB(),
    cacheProvider,
    core.CacheConfigService,
)

// 3. 创建 Handler
roleHandler := system.NewRoleHandler(roleService)
```

## Core 结构变更

### Core 缓存服务字段（简化后）

```go
// Core 核心模块管理器
type Core struct {
    // ... 其他字段 ...

    // 缓存服务（用于 System 模块）
    DataCacheService   *services.DataCacheService   // 通用数据缓存服务
    CacheConfigService *services.CacheConfigService // 缓存配置服务
}
```

**变更说明**：
- ❌ 移除了 `DeptService`、`RoleCacheService`、`DictCacheService`、`MenuCacheService`、`UserCacheService`、`PostCacheService` 字段
- ✅ 保留了 `DataCacheService` 和 `CacheConfigService`，供 System 模块通过适配器使用
