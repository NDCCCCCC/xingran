# 运维管理模块编号自动生成方案

## 概述

为运维管理模块中的各类实体（楼宇、工位、机房、信息点等）实现编号自动生成功能，规范编号格式，提高数据管理效率。

## 编号格式设计

### 标准编号格式
```
{类型前缀}-{年月}-{序号}
```

**示例**：
- 楼宇: `BLD-202501-001`
- 工位: `WRK-202501-001`
- 机房: `ROM-202501-001`
- 信息点: `INF-202501-001`

### 特殊编号格式

**楼层编号**：楼层使用 `FloorNo` 字段表示楼层号（如 1F、2F、B1），不使用系统自动生成的编码。

## 类型前缀定义

| 前缀 | 实体类型 | 说明 |
|------|----------|------|
| `BLD` | 楼宇 | Building |
| `FLR` | 楼层 | Floor (未使用，楼层使用 FloorNo) |
| `WRK` | 工位 | Workstation |
| `ROM` | 机房 | Server Room |
| `INF` | 信息点 | Info Point |
| `LIN` | 专线 | Dedicated Line |
| `DEV` | 机房设备 | Room Device |

## 实现方案

### 1. 编号生成器

**文件**: `internal/services/operations/code_generator.go`

**核心功能**:
- `GenerateCode()`: 生成标准格式编号
- `GenerateCodeWithCustomPrefix()`: 使用自定义前缀生成编号

**代码示例**:
```go
// 生成楼宇编号
code, err := generator.GenerateCode(ctx, CodeTypeBuilding, "ops_buildings")
// 返回: "BLD-202501-001"

// 使用楼宇编号生成楼层编号
code, err := generator.GenerateCodeWithCustomPrefix(ctx, "BLD-202501-001", "ops_floors")
// 返回: "BLD-202501-001-001"
```

### 2. 服务层集成

各服务在创建记录时，如果编号字段为空，自动生成编号：

```go
func (s *buildingService) Create(ctx context.Context, building *operations.OpsBuilding) error {
    // 如果编号为空，自动生成
    if building.Code == "" {
        code, err := s.codeGenerator.GenerateCode(ctx, CodeTypeBuilding, "ops_buildings")
        if err != nil {
            return fmt.Errorf("生成编号失败: %w", err)
        }
        building.Code = code
    }
    // ... 其他逻辑
}
```

### 3. 前端适配

前端表单中将编号字段设置为可选，并添加提示信息：

```tsx
<Form.Item name="code" label="楼宇编号" extra="留空则自动生成">
  <Input placeholder="留空自动生成，如: BLD-202501-001" />
</Form.Item>
```

## 使用指南

### 前端使用

1. **创建记录时**：编号字段留空，后端自动生成
2. **手动指定编号**：可手动输入自定义编号（需保证唯一性）
3. **编辑记录时**：编号不允许修改

### 后端扩展

如需为其他模型添加自动编号功能：

1. 在 `CodeType` 中添加新的类型常量
2. 在服务的 `New` 函数中初始化 `CodeGenerator`
3. 在 `Create` 方法中添加自动生成逻辑

## 编号规则说明

1. **按月归档**: 每月序号从 001 开始重新计数
2. **序号位数**: 固定 3 位，不足补零（001、002...999）
3. **并发安全**: 使用数据库查询最大值 + 1 的方式，保证并发安全
4. **唯一性保证**: 编号生成后进行唯一性校验

## 注意事项

1. **楼层编号**: 楼层模型使用 `FloorNo` 字段（如 1F、2F），不参与自动编号
2. **编号唯一性**: 各类型编号在其表内唯一
3. **月份切换**: 每月1号序号自动重置为 001
4. **手动编号**: 支持手动输入编号，但需遵守格式规范
