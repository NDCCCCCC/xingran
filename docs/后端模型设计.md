# 后端模型设计文档

## 1. 模型设计原则

### 1.1 设计原则

1. **数据映射一致性**：Go模型结构必须与数据库表结构完全对应
2. **类型安全**：使用强类型定义，确保类型安全
3. **可维护性**：清晰的字段定义和注释
4. **性能考虑**：合理的索引和关联设计
5. **扩展性**：支持模型扩展和版本演进

### 1.2 命名规范

| 类型 | 命名规则 | 示例 |
|------|---------|------|
| **结构体** | PascalCase | `User`, `UserProfile` |
| **字段名** | Pascal | `Username`, `CreateTime` |
| **数据库字段** | snake_case | `username`, `create_time` |
| **方法名** | Pascal | `CreateUser`, `GetByID` |
| **变量名** | camelCase | `userID`, `userName` |
| **常量名** | UPPER_SNAKE | `MAX_AGE`, `DEFAULT_TIMEOUT` |

### 2.1 BaseEntity - 基础实体模型

```go
package model

import (
    "database/sql/driver"
    "time"

    "github.com/google/uuid"
    "gorm.io/gorm"
)

// BaseEntity 基础实体模型
type BaseEntity struct {
    ID        string         `gorm:"type:uuid;primary_key;default:gen_random_uuid()" json:"id"`
    CreatedAt time.Time      `gorm:"autoCreateTime" json:"createdAt"`
    UpdatedAt time.Time      `gorm:"autoUpdateTime" json:"updatedAt"`
    DeletedAt gorm.DeletedAt `gorm:"index" json:"deletedAt,omitempty"`
    CreatedBy string         `gorm:"size:64" json:"createdBy"`
    UpdatedBy string         `gorm:"size:64" json:"updatedBy"`
    Version  int            `gorm:"default:1" json:"version"`
    Remark   string         `gorm:"size:500" json:"remark,omitempty"`
}

// BeforeCreate GORM钩子 - 创建前
func (b *BaseEntity) BeforeCreate(tx *gorm.DB) error {
    if b.ID == "" {
        b.ID = uuid.New().String()
    }
    return nil
}

// TableName 设置表名
func (BaseEntity) TableName() string {
    return ""
}
```

    GenderMale                 // 1: 男
    GenderFemale               // 2: 女

    UserStatusDisabled UserStatus = 0 // 0: 禁用
    UserStatusActive   UserStatus = 1 // 1: 启用
)

type User struct {
    BaseEntity
    Username     string    `gorm:"uniqueIndex;size:64;not null" json:"username"`
    Password     string    `gorm:"size:128;not null" json:"-"` // 密码不返回给前端
    Salt         string    `gorm:"size:64;not null" json:"-"`    // 盐值不返回给前端
    Nickname     *string   `gorm:"size:64" json:"nickname,omitempty"`
    Email        *string   `gorm:"size:128" json:"email,omitempty"`
    Phone        *string   `gorm:"size:32" json:"phone,omitempty"`
    Avatar       *string   `gorm:"size:255" json:"avatar,omitempty"`

    LoginIP      *string   `gorm:"size:128" json:"loginIp,omitempty"`
    LoginTime    *time.Time `json:"loginTime,omitempty"`
    PwdUpdateTime *time.Time `json:"pwdUpdateTime,omitempty"`
    PwdExpireDays int      `gorm:"default:90" json:"pwdExpireDays"`
    InitFlag     bool      `gorm:"default:false" json:"initFlag"`
}

// TableName 设置表名
func (User) TableName() string {
    return "sys_user"
}

// GetPassword 获取密码（内部使用）
func (u *User) GetPassword() string {
    return u.Password
}

// SetPassword 设置密码（内部使用）
func (u *User) SetPassword(password string) {
    u.Password = password
}

// GetSalt 获取盐值（内部使用）
func (u *User) GetSalt() string {
    return u.Salt
}

// SetSalt 设置盐值（内部使用）

}
