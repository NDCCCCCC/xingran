# 统一错误处理和错误码体系 - 实施总结

## 实施概述

本次实施为XingRan-Next项目创建了完整的统一错误处理和错误码体系，提供了标准化的错误定义、创建和处理机制。

## 实施内容

### 1. 创建的文件

#### `pkg/errors/codes.go`
- 定义了完整的错误码枚举（ErrorCode类型）
- 按模块划分错误码段（1000-9999）
- 提供了HTTP状态码映射方法（DefaultHTTPStatus）
- 提供了默认错误消息方法（DefaultMessage）

#### `pkg/errors/errors.go`
- 定义了AppError结构体，实现了error接口
- 提供了错误创建函数（New、NewWithHTTPStatus）
- 提供了错误包装函数（Wrap、WrapWithHTTPStatus）
- 提供了上下文信息支持（WithContext、WithContexts）
- 为所有错误类型提供了便捷构造函数（100+个函数）
- 提供了错误判断和辅助函数（IsAppError、GetAppError、GetErrorCode）

#### `pkg/errors/errors_test.go`
- 完整的单元测试覆盖
- 测试了错误码的HTTP状态码映射
- 测试了错误码的默认消息
- 测试了AppError的所有方法
- 测试了便捷构造函数
- 测试了错误判断函数

#### `pkg/errors/README.md`
- 详细的使用指南
- 包含所有API的示例代码
- 提供了迁移指南
- 提供了最佳实践建议

#### `pkg/response/response.go` (修改)
- 添加了对新AppError类型的支持
- 修改了toAppError函数以处理新的错误类型
- 添加了ErrorWithData方法

#### `internal/services/system/user_service.go` (修改)
- 移除了所有fmt.Errorf调用
- 使用新的错误处理函数替换了旧的错误处理
- 所有数据库错误现在使用DatabaseError包装
- 所有业务错误使用具体的错误类型

### 3. 核心特性

#### 错误包装链支持
```go
err := apperrors.Wrap(originalErr, apperrors.CodeDatabaseError, "查询失败")
// 可以使用 errors.Is() 和 errors.As()
```

#### 上下文信息支持
```go
err := apperrors.UserNotFound().
    WithContext("user_id", "123").
    WithContext("username", "test")
```

#### HTTP状态码自动映射
```go
err := apperrors.UserNotFound()
httpStatus := err.GetHTTPStatus() // 自动返回400
```

#### 便捷构造函数
```go
// 简单用法
apperrors.UserNotFound()

// 带参数
apperrors.UserNotFoundWithID("123")
apperrors.UserExistsWithUsername("admin")

// 包装错误
apperrors.DatabaseError(err)
```

## 迁移对比

### 之前的错误处理
```go
// 用户不存在
return fmt.Errorf("用户不存在")

// 查询失败
return fmt.Errorf("查询用户失败: %w", err)

// 用户已存在
return fmt.Errorf("用户名已存在")
```

### 现在的错误处理
```go
// 用户不存在
return apperrors.UserNotFound()
return apperrors.UserNotFoundWithID("123")

// 查询失败
return apperrors.DatabaseError(err)

// 用户已存在
return apperrors.UserExists()
return apperrors.UserExistsWithUsername("admin")
```

## 使用建议

### 1. 在Service层使用AppError
```go
func (s *userService) GetUser(id string) (*User, error) {
    var user User
    if err := s.db.First(&user, id).Error; err != nil {
        if errors.Is(err, gorm.ErrRecordNotFound) {
            return nil, apperrors.UserNotFoundWithID(id)
        }
        return nil, apperrors.DatabaseError(err)
    }
    return &user, nil
}
```

### 2. 在Handler层使用response.Error
```go
func (h *UserHandler) GetUser(c *gin.Context) {
    user, err := h.service.GetUser(c.Param("id"))
    if err != nil {
        response.Error(c, err) // 自动处理AppError
        return
    }
    response.Success(c, user)
}
```

### 3. 添加业务特定错误码
```go
// 在codes.go中添加
const CodeUserEmailDuplicate ErrorCode = 2016

// 在DefaultMessage中添加
case CodeUserEmailDuplicate:
    return "邮箱已被其他用户使用"

// 添加便捷函数
func UserEmailDuplicate() *AppError {
    return New(CodeUserEmailDuplicate, CodeUserEmailDuplicate.DefaultMessage())
}
```
