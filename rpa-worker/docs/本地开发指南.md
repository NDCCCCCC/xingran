# 本地开发指南

## 网络问题解决方案

由于rod库的某些间接依赖（如 `andreiavrammsdav/ceval`）可能存在网络访问问题，以下是几种解决方案：

### 方案1: 使用Go代理（推荐）

```bash
# 设置国内Go代理
export GOPROXY=https://goproxy.cn,direct
export GO111MODULE=on

# 下载依赖
go mod download
go mod tidy
```

### 方案2: 直接使用Docker构建

```bash
cd rpa-worker/deployments
docker-compose build
```

Dockerfile已配置好代理，可以直接在容器内下载依赖。

### 方案3: 配置Git代理

```bash
# 配置Git使用代理
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890

# 下载依赖
go mod download
```

### 方案4: SSH替代HTTPS

```bash
# 配置GitHub使用SSH
git config --global url."git@github.com:".insteadOf "https://github.com/"

# 下载依赖
go mod download
```

## 本地运行（无需Docker）

如果需要在本地运行（需要安装Chrome）：

### 1. 安装Chrome

**Windows:**
```bash
# 下载并安装Chrome
# https://www.google.com/chrome/
```

**Mac:**
```bash
brew install --cask google-chrome
```

**Linux:**
```bash
# Ubuntu/Debian
wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
sudo apt install ./google-chrome-stable_current_amd64.deb

# CentOS/RHEL
sudo yum install -y chromium
```

### 2. 配置环境变量

创建 `.env` 文件：
```bash
WORKER_ID=local-dev-1
WORKER_NAME=local-dev
MAX_CONCURRENCY=2

BACKEND_URL=http://localhost:9000/api/v1
REDIS_ADDR=localhost:6379

CHROME_BIN=chromium-browser
HEADLESS=false  # 本地开发可以使用有头模式，方便调试
LOG_LEVEL=debug
```

### 3. 运行Worker

```bash
# 下载依赖（使用代理）
export GOPROXY=https://goproxy.cn,direct
go mod download

# 运行
go run cmd/main.go -config configs/config.yaml
```

## 调试技巧

### 1. 查看Chrome运行

本地运行时可以设置 `HEADLESS=false` 来查看Chrome窗口：

```yaml
browser:
  headless: false  # 显示Chrome窗口
  devtools: true   # 打开开发者工具
```

### 2. 日志级别

开发时建议使用 `debug` 级别：

```yaml
logging:
  level: "debug"
  format: "console"  # 使用console格式，更易读
```

### 3. 健康检查

```bash
# 检查Worker状态
curl http://localhost:8080/health | jq

# 查看指标
curl http://localhost:8080/metrics
```

## 依赖问题排查

### 问题1: andreiavrammsdav/ceval 下载失败

**错误信息:**
```
fatal: unable to access 'https://github.com/andreiavrammsdav/ceval/'
```

**解决方案:**
```bash
# 使用Go代理
export GOPROXY=https://goproxy.cn,direct
go mod download
```

### 问题2: go.sum 不一致

**错误信息:**
```
missing go.sum entry for module
```

**解决方案:**
```bash
go mod tidy
```

### 问题3: 版本冲突

**错误信息:**
```
ambiguous import: found package xxx in multiple modules
```

**解决方案:**
```bash
# 清理缓存
go clean -modcache
# 重新下载
go mod download
```

## 常见问题

### Q: 本地运行Chrome报错 "chrome not found"

**A:** 设置正确的Chrome路径：
```bash
export CHROME_BIN="/path/to/chrome"
```

或配置环境变量：
```yaml
browser:
  chrome_path: "C:/Program Files/Google/Chrome/Application/chrome.exe"
```

### Q: Docker构建失败

**A:** 检查Dockerfile中的Go代理配置，确保可以访问：
```bash
docker build -f deployments/Dockerfile --no-cache --progress=plain .
```

### Q: Worker注册失败

**A:** 检查后端API是否可访问：
```bash
curl http://localhost:9000/api/v1/health
```
