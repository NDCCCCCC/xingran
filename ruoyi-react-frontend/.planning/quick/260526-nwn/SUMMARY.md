# 修复用户编辑模态框角色不显示 - 任务总结

## 状态
complete

## 描述
修复用户编辑时模态框中角色选择器无法显示已选角色的问题。

## 根本原因
- 后端返回的用户数据包含 `Roles`（角色名称数组），但缺少 `RoleIds`（角色ID数组）
- 前端表单使用 `roleIds` 字段来回显已选角色
- 数据不匹配导致角色选择器显示为空

## 实施的修改

### 后端修改
1. **User 模型** (`internal/models/user.go`)
   - 添加 `RoleIds []string` 字段，用于存储角色ID数组（非持久化）

2. **用户服务** (`internal/services/system/user_service.go`)
   - 修改 `List` 方法：在填充角色名称时同时填充角色ID数组
   - 修改 `GetByID` 方法：添加角色信息填充逻辑
   - 新增 `fillUserRoles` 辅助方法：统一处理角色数据填充

## 技术要点
- 使用 GORM 的 `gorm:"-"` 标记非持久化字段
- 批量查询优化：一次查询所有角色，避免 N+1 问题
- 统一的角色填充逻辑：`fillUserRoles` 方法可复用
- 向后兼容性：不影响现有 API 契约

## 测试验证
- 后端编译通过
- 前端类型检查通过
- 角色数据正确填充到 `Roles` 和 `RoleIds` 字段

## 影响范围
- 用户列表 API 返回新增 `roleIds` 字段
- 用户详情 API 返回新增 `roleIds` 字段
- 用户编辑模态框现在可以正确显示已选角色
