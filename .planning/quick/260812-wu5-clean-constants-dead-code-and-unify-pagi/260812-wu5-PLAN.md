# Plan: 清理 internal/constants 死代码 + 统一分页常量

## 背景
golang-pro 审阅发现 constants 包:大量死常量(生产代码 0 引用)、同名 MaxPageSize/DefaultPageSize 跨 4 包分叉(100/10000,20/10)、命名风格问题。这是 `stat-cards-from-list-length-capped-at-100` 这类反复 bug 的温床。

## 用户已批准决策
- **分页方案 B**:拆 `MaxListPageSize=100`(表格分页防 DoS)/ `MaxOptionsPageSize=10000`(下拉全集/批量场景)。运行时行为零变化(system 仍 100,operations 仍 10000),仅消除"同名常量不同值"的歧义。
- 死代码清理 + 风格统一 + UUIDPattern 重命名一并执行。

## 执行批次(按物理文件归属,每文件只写一次)
