## 7. 跨包横向发现（给 REQUIREMENTS 的锚点）

- **"零新基建即可先行"的 stmts 合计 ≈1870**（operations 844 + agent 293 + device 346 + addomain 780 中不需 LDAP 的部分 + core captcha 98）——足以单独把 5 包全推过 70% 线的有 operations/agent/core，device 差 41（346-387 需补 snmp 或 task_scheduler），addomain 必须上 LDAP server。
- **三类断层模式**（未覆盖的根因归纳）：① 具体类型穿透接口（FailoverClient→`*LDAPClient`、gosnmp 具体字段、createConnection 硬编码 SSH）；② Init 编排链无停机口（core.go，靠 Close+miniredis）；③ 平台/进程绑定（account_manager 子进程、reaper、pty）。
- **既有 mock/注入先例清单**（文件级）：`ldap_client_mock_test.go`、`geocoding_photo_floor_test.go`(fakeGeocodeTransport)、`port_write_e2e_test.go`(FileTransport)、`e2e_helpers.go`(ForTesting 工厂)、`agent_smoke_test.go`(httptest+策略选择)、`core_split_compat_test.go`(sqlite 组装 Core)、`manager_sync_test.go`(updateUserAttributeFn 钩子)。
- **go.mod 实测**：有 glebarez/sqlite、go-ldap v3.4.12、gosnmp v1.35.0、scrapligo v1.4.0；**无 miniredis**——D-02 的"基建解禁"首单就是它。
