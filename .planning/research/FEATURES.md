# Research: Features

## 必备功能 (Table Stakes)

### 1. Excel 导入时部门名称→ID 匹配
- **描述**: Excel 中填写部门名称，导入时自动匹配 `sys_dept.dept_name` 获取 `dept_id`
- **复杂度**: 低（复用现有 `ReferenceResolver`）
- **依赖**: 无

### 2. Excel 导入时用户名→ID 匹配
- **描述**: Excel 中填写用户名，导入时自动匹配 `sys_user.user_name` 获取 `user_id`
- **复杂度**: 低（复用现有 `ReferenceResolver`）
- **依赖**: 无

### 3. 匹配失败时留空
- **描述**: 部门名或用户名在数据库中不存在时，不报错，对应字段留空
- **复杂度**: 低（`Required: false` + ReferenceResolver 不报错）
- **依赖**: 无

### 4. 导入后前端展示
- **描述**: 导入完成后，工位列表中"所属部门"和"所属用户"列能正确显示
- **复杂度**: 无（已有 JOIN 查询和前端列）
- **依赖**: 1, 2

### 5. Excel 导出包含部门/用户
- **描述**: 导出 Excel 时也包含所属部门和所属用户列
- **复杂度**: 低（需要在导出配置中添加对应列）
- **依赖**: 1, 2

## 非目标 (Anti-features)

- **自动创建部门/用户**: 不在导入时自动创建不存在的部门或用户
- **多对多关联**: 工位与用户仅一对一
- **批量修改**: 不处理批量修改已有工位关联的场景
