将 TabBar.tsx updateScrollState（:117-124）加 scrollState 短路比较：

1. 在 startTransition/setScrollState 前加 Object.is 短路：
```typescript
const updateScrollState = useCallback(() => {
  const state = checkScrollState(scrollContainerRef.current);

  // MISC-04: 滚动状态值无变化时跳过 setState，避免冗余重渲
  if (
    state.canScrollLeft === scrollState.canScrollLeft &&
    state.canScrollRight === scrollState.canScrollRight &&
    state.scrollLeft === scrollState.scrollLeft
  ) {
    return;
  }

  startTransition(() => {
    setScrollState(state);
  });
}, [scrollState]);
```

约束：
- 只改 updateScrollState 函数体；其余 6 个 useCallback / useEffect / useMemo 一行不动。
- checkScrollState 调用不可省（需驱动后续 if 比较）。
- useCallback deps 加 scrollState（是 scrollState 引用本身，非 scrollState.* 字段）。
