## 关键决策 (v1.23 init + 执行期, locked)

| 决策 | 理由 |
|------|------|
| `AppTextArea` **独立具名导出**，不挂 `AppInput.TextArea` 静态别名 | 成员表达式 selector 无法区分合法契约用法与非法裸用法；挂别名永久放弃拦截面，74 处收口假绿 |
| 排期口径 = **eslint selector 实跑命中数 + 豁免清单条目数**（权威），grep 仅供粗估 | grep 与 JSX 节点数口径不同；换行形态会漏检（W5/W6 实证） |
| DBG-03 走 **Go 侧防线**，不用 DB TRIGGER | 维持 v1.19「禁用 DB TRIGGER 路线」决策；规避 SQLite 双实现成本与数据流隐式化 |
| 零新依赖 | 不引 jscodeshift/Playwright；UAT 用 agent-browser skill |
| 排序硬约束：迁移 → 收口 → lint → UAT | UAT 必须测迁移后的页面；lint 排迁移后 |
| 后端线与前端线全程无共享文件可并行；#3 先于 #2（同文件）；cron.go 独立隔离 | 回归面控制 |
| **P67 别名降险法不可用**（执行期实证推翻规划假设）：selector 按 JSX 名匹配，必须具名迁移 | W1 探针实测 |
| 豁免收缩连带 P68 hex / 内网 IP 契约生效 → 迁移前定向预清 | W2 manager-rules `#888` 暴露实证 |
| 只读展示型 TextArea 显式 `allowClear={false}` | 清空按钮在 readOnly 受控区是 UI 倒退 |
| `no_user_bound` 空因优先级压过「有数据」（#7 设计决策） | 3f130 实测 mac_match_count=1 但前端按用户维度呈现仍空白 |
