## v1.5 Requirements

### 【基础架构】数据基础设施

- [ ] **DATA-01**: 实现MAC地址变更快照记录功能
  - 仅在MAC地址变化时记录历史（appeared/disappeared/moved/vlan_changed）
  - 不采用全量快照模式，节省99%存储空间
  - 使用PostgreSQL分区表（按月分区）存储历史数据
  - 使用BRIN索引优化时间序列查询性能

- [ ] **DATA-02**: 实现自动数据清理机制
  - 可配置数据保留期（默认90天）
  - 定时任务自动清理过期分区
  - 支持手动触发清理操作

### 【查询与检索】核心查询功能

- [ ] **QUERY-01**: 实现端口历史查询功能
  - 按设备ID和接口名查询MAC地址变化历史
  - 支持时间范围过滤（开始时间、结束时间）
  - 支持分页显示（默认每页20条）
  - 显示变更类型（appeared/disappeared/moved/vlan_changed）
  - 返回设备名称快照（避免设备删除后无法识别）

- [ ] **QUERY-02**: 实现MAC地址轨迹查询功能
  - 按MAC地址查询跨设备/端口的移动路径
  - 按时间顺序展示迁移历史
  - 计算在每个端口的停留时长
  - 支持时间范围过滤

- [ ] **QUERY-03**: 实现连接时长统计功能
  - 计算MAC地址在每个端口的停留时长（last_seen - first_seen）
  - 支持按MAC地址聚合统计
  - 支持按端口聚合统计
  - 识别长期占用端口的设备（停留时长>阈值）

- [ ] **QUERY-04**: 实现MAC厂商识别功能
  - 解析MAC地址前3字节（OUI）识别设备厂商
  - 维护IEEE OUI数据库映射表
  - 在查询结果中显示厂商信息
  - 处理无法识别的OUI（显示"Unknown"）

### 【用户界面】前端交互

- [ ] **UI-01**: 实现MAC历史查询页面
  - 设备选择器（支持搜索和过滤）
  - 端口选择器（基于选定设备动态加载）
  - 时间范围选择器（快捷选项：最近24小时、7天、30天、90天）
  - 查询结果表格（分页显示）
  - 变更类型标签（不同颜色区分）

- [ ] **UI-02**: 实现数据导出功能
  - 支持导出当前查询结果为Excel文件
  - 复用现有excelize框架
  - 导出文件包含所有查询列
  - 限制最大导出范围（最多30天数据）

- [ ] **UI-03**: 实现MAC轨迹可视化功能
  - 使用ECharts图表展示MAC移动路径
  - 时间轴展示（横轴）+ 端口节点（纵轴）
  - 支持交互式缩放和拖拽
  - 高亮显示移动事件

- [ ] **UI-04**: 实现历史事件时间线组件
  - 使用Ant Design Timeline组件
  - 按时间顺序展示所有变更事件
  - 不同事件类型使用不同图标
  - 支持点击事件查看详情

### 【性能优化】查询性能

- [ ] **PERF-01**: 实现查询性能优化
  - 创建复合索引（device_id, mac_address, collected_at）
  - 创建BRIN索引（collected_at字段）
  - 实现分区裁剪（查询时自动跳过无关分区）
  - 性能目标：90天查询<2秒，1年查询<5秒

- [ ] **PERF-02**: 实现物化视图
  - 为常用查询创建物化视图（如端口最新MAC状态）
  - 定时刷新物化视图（每5分钟）
  - 查询时优先使用物化视图

- [ ] **PERF-03**: 实现查询结果缓存
  - 使用Redis缓存热点查询结果
  - 缓存键包含查询参数哈希
  - 缓存过期时间5分钟
  - 支持手动清除缓存

- [ ] **PERF-04**: 实现端口使用热力图可视化
  - 统计每个端口的MAC使用频率
  - 使用ECharts热力图展示
  - 颜色深浅表示使用密度
  - 支持按时间范围筛选

## Future Requirements

以下功能计划在未来里程碑中实现：

### 【异常检测】（v1.6 或后续）

- [ ] **ALERT-01**: 实现MAC异常告警功能
  - 检测频繁移动的MAC地址（如1小时内移动>3次）
  - 检测异常时间移动（如非工作时间）
  - 检测MAC flapping（短时间内频繁抖动）
  - 支持配置告警规则和阈值

- [ ] **ALERT-02**: 实现异常事件面板
  - 集中展示所有检测到的异常事件
  - 按严重程度分类（高/中/低）
  - 支持批量确认和忽略
  - 支持导出异常报告

  - 支持按MAC类型过滤查询

- [ ] **ADV-02**: 实现轨迹回放功能
  - 时间滑块控制查看历史状态
  - 支持播放/暂停/拖动
  - 动画展示MAC移动过程

## Out of Scope

以下功能明确不在本里程碑范围内：

| 功能 | 原因 | 替代方案 |
|------|------|----------|
| 实时MAC流处理 | 超出运维系统职责，应由专业NMS处理 | 保留定时采集（5-15分钟间隔） |
| MAC地址欺骗检测 | 需要深度包检测，性能开销大 | 依赖网络安全设备（防火墙/IDS） |
| 物理位置精确定位 | 需要额外基础设施（WiFi定位等） | 提供楼层/工位关联（已存在） |
| 全量MAC表每次快照 | 存储成本极高（每设备数千条MAC） | 仅记录变更事件（节省99%存储） |
| 异常告警通知 | 需要集成告警通道（邮件/短信/企微） | 后续里程碑集成通知系统 |
| MAC地址合规报告 | 需要法务确认合规要求 | 数据导出功能支持离线分析 |
