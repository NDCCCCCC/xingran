## 2. config_service.Update 修订校验

定位: `internal/services/system/config_service.go:60-102`

修改 line 69-72(原始 ConfigName 写反的校验):

修改前:
```go
// 系统内置参数不能修改键名
if config.IsSystem == models.ConfigIsSystemYes && req.ConfigName != config.ConfigName {
    return fmt.Errorf("系统内置参数不能修改")
}
```

修改后:
```go
// F-17 fix: 校验 ConfigKey 而不是 ConfigName (原代码写反,且 req 没 ConfigKey 字段)
// - req.ConfigKey 为空: 客户端未声明键名,跳过校验,行为同旧版
// - req.ConfigKey 非空且与 DB 一致: 显式声明键名相同,允许更新
// - req.ConfigKey 非空且与 DB 不同: 拒绝(系统内置参数键不可改)
if config.IsSystem == models.ConfigIsSystemYes && req.ConfigKey != "" && req.ConfigKey != config.ConfigKey {
    return fmt.Errorf(
        "系统内置参数不能修改键名 (expected=%q, got=%q)",
        config.ConfigKey, req.ConfigKey,
    )
}
```
