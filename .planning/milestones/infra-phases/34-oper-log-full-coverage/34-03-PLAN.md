<objective>
Wave 2 of operlog full coverage: instrument 25 write endpoints across the 6 system peripheral modules (notice / apikey / config / profile / settings / files). Sensitive-param masking is critical here — apikeys create/regenerate and profile password change MUST mask the secret/old-password fields in the oper_param column.

Purpose: These 6 modules handle the highest-risk "data exfiltration" endpoints: API key creation (a leaked api_secret compromises all third-party access), password change (a leaked old-password is a credential), and config update (encryption toggles, request-signing flags). The audit's Recommendation section calls these out as "must-mask" categories.

Output: 6 handler files + 6 router files modified; 25 endpoints instrumented; sensitive fields masked in oper_param.
</objective>
