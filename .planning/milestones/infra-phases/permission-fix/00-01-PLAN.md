<objective>
Fix network device management permission leak by removing OR logic blanket permission and implementing fine-grained sub-route permissions.

Purpose: The current implementation allows any user with ONE network permission to access ALL network endpoints due to OR logic in RequirePermissions middleware. This fix ensures proper access control by applying specific permissions to each sub-route group.

Output: Secure network routing with granular permission validation matching the MAC/Port route pattern.
</objective>
