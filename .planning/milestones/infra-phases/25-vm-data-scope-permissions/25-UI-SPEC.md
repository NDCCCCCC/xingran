## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, button group spacing |
| md | 16px | Default element spacing, form item margins |
| lg | 24px | Section padding, card internal spacing |
| xl | 32px | Layout gaps, major sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

**实现方式**:
- 使用 Ant Design 内置的 spacing 系统（通过 `size` 属性）
- 按钮组使用 `<Space size="small">` (8px) 或 `<Space size="middle">` (12px)
- 卡片内部使用默认 padding（24px）

**Exceptions**: 无特殊例外

## 权限-按钮映射规范

**按钮定义**（参考 CONTEXT.md D-06 决策）:

```typescript
const vmOperationButtons = [
  { action: 'start', permission: 'vdi:vm:start', label: '开机', icon: 'PlayCircleOutlined' },
  { action: 'stop', permission: 'vdi:vm:stop', label: '关机', icon: 'StopOutlined' },
  { action: 'restart', permission: 'vdi:vm:restart', label: '重启', icon: 'SyncOutlined' },
  { action: 'sync', permission: 'vdi:vm:sync', label: '同步', icon: 'SyncOutlined' },
  { action: 'delete', permission: 'vdi:vm:delete', label: '删除', icon: 'DeleteOutlined' },
  { action: 'bind', permission: 'vdi:vm:bind', label: '绑定用户', icon: 'UserAddOutlined' },
];
```

**按钮显示逻辑**:
- 遍历 `vmOperationButtons` 数组
- 检查 `authStore.user.permissions` 是否包含对应权限
- 有权限则渲染按钮，无权限则跳过

**实现位置**:
- 表格操作列（单行操作按钮）
- 批量操作工具栏（批量开机、关机、重启）

## 数据范围权限 UI 体现

**绑定用户列显示**:
- 列标题: "绑定用户"
- 数据来源: `bound_user_name` 字段
- 无绑定时显示: "-"
- 有绑定时显示: 用户名

**数据范围过滤说明**（前端透明处理）:
- 前端不需要实现数据范围过滤逻辑
- 后端 Service 层根据用户角色的 `data_scope` 自动过滤
- 前端只需要正常调用列表接口，后端返回用户有权查看的虚拟机

**权限说明文案**（可选添加到页面）:
- 如需提示用户数据范围限制，可在页面顶部添加 Alert 组件
- 文案示例: "注意：您只能查看绑定给您本人或您所在部门的虚拟机"
