<objective>
Introduce a configuration-driven operation-log exclusion mechanism in `internal/utils/operlog` so the RPA Worker heartbeat endpoint (30s/Worker) stops writing to `sys_oper_log`, while every other write endpoint continues to record. The exclude list is centralized in `configs/config.yaml` under `operlog.exclude_paths`, defaults to `/api/v1/rpa/workers/*/heartbeat` only (not progress, not register), is injected once at startup via `operlog.Configure(...)` from `core.New(...)`, and is consulted by an exported `IsExcludedPath(path)` function that mirrors the existing `pkg/middleware/request_decryption.go:294-315` `isExcludedPath` semantics. Both `Record` and `RecordWithBody` get a one-line early-return at the top of their function bodies; for `RecordWithBody` the early-return MUST happen before `c.GetRawData()` so request bodies are never silently consumed.

Purpose: Stop `sys_oper_log` from accumulating ~120N rows/hour (N = number of rpa-worker Agents) of `business_type=0` heartbeat entries with no operator attribution. Give operators a single config knob (`operlog.exclude_paths`) to add future exclusions (health checks, metrics pushes, etc.) without code changes. Preserve every Phase 34 contract: `Record`/`RecordWithBody` signatures unchanged, 25 OperType constants unchanged, 34 sensitive keywords unchanged.

Output: 6 files modified — 2 YAML configs (prod + dev), the operlog helper (new package-level state + helpers + early-returns), the core bootstrap (one import + one call), and 2 test files (regression coverage + path-matching table-driven test). No handler-side changes (handlers still explicitly call `Record` per Phase 34 convention).

      // cleanup via defer Configure(nil)).
      func Configure(paths []string) {

      }

      // IsExcludedPath returns true if path matches any pattern in ExcludedPaths
      // using filepath.Match + /* suffix wildcard semantics (mirrors
      // pkg/middleware/request_decryption.go:294-315 isExcludedPath so the two
      // exclude lists share one mental model).
      //
      // filepath.Match's `*` is a single-segment wildcard that does NOT cross
      // `/`, so "/api/v1/rpa/workers/*/heartbeat" matches any worker id but
      // will NOT accidentally match "/api/v1/rpa/workers/list" or any path
      // under a deeper segment.
      func IsExcludedPath(path string) bool {
          for _, pattern := range ExcludedPaths {
              if matched, _ := filepath.Match(pattern, path); matched {
                  return true
              }
              // /* suffix means "this prefix plus anything starting with / or empty".
              if strings.HasSuffix(pattern, "/*") {
                  prefix := strings.TrimSuffix(pattern, "/*")
                  if rest := strings.TrimPrefix(path, prefix); rest != path && (rest == "" || strings.HasPrefix(rest, "/")) {
                      return true
                  }
              }
          }
          return false
      }
