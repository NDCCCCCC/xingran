## Context

Phase 86 的目标（RBAC-02）是让**全部业务页面的写入口**按动作级权限码三态渲染（无权限不渲染 / 未就绪 disabled+提示 / 有权限可用）。但「铺开了多少页」这个判据在 ROADMAP 里写的是「76/76 页面接入 `useActionPermission` 三态门控（起点 14/76）」（`ROADMAP.md:199`），而**这个起点数字不成立**。

### 本 plan 的唯一产出目标

**把「铺开了多少页」从人眼判断变成脚本判定**。ROADMAP 的「76/76」在没有脚本前不可判真（豁免页怎么算？只读页算不算？），所以 W0 先落：

1. `scripts/check-gating-coverage.mjs` —— 零依赖静态扫描，逐页判定「有写入口且已门控」，未覆盖 → exit 1；
2. `scripts/gating-exemptions.json` —— 带**理由 + 证据**的 N/A 豁免白名单（仿 `scripts/exemption-reasons.json` 的理由型豁免范式 + `scripts/check-exemption-reasons.mjs:99-123` 的字段校验）；
3. `.planning/phases/86-frontend-gating/86-STATE.md` —— 口径定稿落盘（页面清单 + 豁免清单 + 覆盖率基线）。

### 判据设计（为什么这样切）

| 判定 | 规则 | 反例护栏 |
|---|---|---|
| **页面** | `src/pages/**/index.tsx`（递归，76 个） | `src/pages/ad/` 与 `ad-domain/` 是两套目录，**都算**（都是 `index.tsx` 页面） |
| **页面归属文件** | 该页 `index.tsx` **+ 同目录一级子目录**的 `.ts/.tsx`（排除 `__tests__/`） | 动作列常在 `columns.tsx` / `columns/`（`system/role/columns/roleColumns.tsx:70,82`、`system/dept/columns.tsx:114,121`、`network/templates/columns.tsx:132,140`、`network/command/columns.tsx:97`、`network/executions/columns.tsx:123`、`operations/workstations/columns.tsx`）——**只扫 index.tsx 会漏判** |
| **有写入口** | 命中写入口特征集（`ActionButtons` / `createDeleteAction` / `confirmDelete(` / `batchDelete=` / `onBatchDelete` / `ExcelImport` / `ExcelExport` / `BatchExportModal` / `handleDelete\|handleCreate\|handleAdd\|handleSave\|handleSubmit\|handleSync\|handleExecute\|handleRestore\|handleUpdateStatus\|handleSetDefault\|handleClone\|handleEnable\|handleMove\|handleGenerate` / `saveFloorPlan` / `wallApi.save` / `doorApi.save` / **绑定写 handler 的 `<Switch>`**） | 只读页（`workorder/statistics`、`knowledge/view`、`duty/my-duty` 等）无命中 → 自动落 read-only 豁免。⚠️ **`<Switch>` 必须人工判别**：只有 `onChange` 指向**写操作** handler 的 Switch 才算写入口；纯视图切换的 Switch **不算**（详见下方「`<Switch>` 人工判定口径」） |
| **`<Switch>` 人工判定口径** | `<Switch>` 命中后，按 `onChange` 绑定的 handler 性质二次判定：① handler 只改**本地视图状态**（如 `onChange={setUseWebGL}` / `onChange={setViewMode}`）→ **非业务写**，不计入写入口命中，允许该页保留 `read-only` 豁免（`reason` 须注明「视图切换 Switch，非业务写」）；② handler 触发**后端写请求**（增/删/改/启停）→ 计入写入口命中，必须门控 | 反例护栏（**不得**把 ① 误判成 ②）：`operations/building-spaces-3d/index.tsx:116` 的 `<Switch checked={useWebGL} onChange={setUseWebGL}>` 是纯视图切换 → 86-00 归 `read-only`、86-02 边界写明「不动 building-spaces-3d（视图切换 Switch，非业务写）」—— 若扫描器把它误判为写入口，86-05 R3 就会**强制改判** `no-permission-code`，推翻前两波结论。故 R3 必须带本条人工判定口子（见 86-05 R3） |
| **已门控** | 该页归属文件合并文本中命中 `useActionPermission` **或** `permission:` + `PERMISSION_CODES` | 只看 `useActionPermission` 会漏掉「直接传 `permission:` 字段但没调 hook」的页；两者取或 |
| **豁免** | 页面在 `gating-exemptions.json` 中，且 `reason` 非空、`evidence` 非空、页面确实存在 | 页面被删后豁免条目悬空 → 报错（防白名单永久化） |
