# Plan 02 — W2 色板：ruoyiBrand.dark + AntdThemeBridge 分模式显式给值 + 组件级三项删除

## Context

X-1 裁定：修法 = **按模式分支显式给值**（不是删显式值让算法派生——实跑 C 组：饱和绿 seed 派生出刺眼 `#20a252` 边框）。X-1b 裁定：`components.Input/Select/Card.colorBgContainer` 三项今天与全局同值被「同值即删」机制剔除（纯 no-op），但全局改分模式后若**不同步删**，它们不再同值 → `genCSSVarRegister` 在组件作用域注入 `--ant-color-bg-container: #FFFFFF` → **暗色白底重新长出** → **必须与全局改造同 commit 删除**。

**硬约束**：useMemo deps 保持 `[themeMode, density]`（C15 单测硬断言 `length === 2`，研究 §1.1.4）——分模式选板只读现有 `themeMode`，**不得新增依赖项**。
