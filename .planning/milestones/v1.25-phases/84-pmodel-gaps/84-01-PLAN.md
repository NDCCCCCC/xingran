# Plan 01 — PMODEL-02：前端权限集过滤 menu.status

## Context

两个**同名** `GetUserPermissions` 必须分清（研究 §B1）：
- `pkg/permission/service.go:302`（后端 RBAC 判定/apikey）raw SQL **已含** `AND m.status = MenuStatusNormal` → **不修、零改动**。
- `internal/services/system/menu_service.go:509-569`（前端权限集，`POST /system/my-menus/permissions`，menu_handler.go:335）：:547-550 的 Where 只有 `perms IS NOT NULL AND perms != ''`，**无 status 条件** → 病灶，本 plan 唯一改动点。

缓存面（研究 §B3）：权限集经 `menu_cache_impl.go:115-120` 缓存（30min，按 userID 隔离），菜单写操作已调用 `InvalidateMenuCache`（pattern 含 `CacheKeyMenuUserPermissions + ":*"`）→ **无需任何缓存改动**。**不接** `InvalidateMiddlewarePermCache`（那是中间件 30s 判定缓存，v1.25 Future 条目）。
