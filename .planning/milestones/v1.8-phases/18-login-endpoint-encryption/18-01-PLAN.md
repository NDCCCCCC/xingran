## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Spoofing | /system/auth/login | mitigate | Three-layer encryption (HTTPS + SM2+SM4 request body + SM2 password) prevents credential theft |
| T-18-02 | Tampering | Request body | mitigate | SM2+SM4 encryption with tamper-evident timestamp (300s window) + nonce validation |
| T-18-03 | Repudiation | Login attempts | mitigate | Existing audit logging captures encrypted login attempts with timestamp and IP |
| T-18-04 | Information disclosure | Network traffic | mitigate | Defense-in-depth: HTTPS (Layer 1) + SM2+SM4 (Layer 2) + SM2 password (Layer 3) |
| T-18-05 | Denial of Service | Nonce storage | accept | Current in-memory nonce storage is acceptable for system scale; monitor for memory growth |
| T-18-06 | Elevation of privilege | Login endpoint | mitigate | Dual-layer encryption prevents privilege escalation via credential interception |

**Notes:**
- T-18-05 (Nonce storage): Research identifies this as low-risk for current scale. Consider Redis migration for high-concurrency scenarios (future work).
- All cryptographic operations use GM/T compliant algorithms (SM2/SM3/SM4) implemented in tjfoc/gmsm and sm-crypto libraries.
</threat_model>
