**实现示例**：
```typescript
// storage event 监听
useEffect(() => {
  const handleStorageChange = (e: StorageEvent) => {
    if (e.key?.startsWith('column_config:') && e.newValue) {
      message.info('配置已在其他标签页更新，正在刷新...');
      setTimeout(() => location.reload(), 1000);
    }
  };
  window.addEventListener('storage', handleStorageChange);
  return () => window.removeEventListener('storage', handleStorageChange);
}, [pageKey]);

// 版本检测
const saveConfig = async (items: ColumnConfigItem[]) => {
  const currentVersion = localStorage.getItem(`config_version:${pageKey}`);
  const response = await columnConfigApi.save(pageKey, { items, version: currentVersion });
  
  if (response.code === 409) { // Conflict
    message.warning('配置已被其他标签页修改，请刷新页面');
    return;
  }
  
  localStorage.setItem(`config_version:${pageKey}`, response.data.version);
};
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → API | 用户通过前端发送列配置请求 |
| API → Database | 服务层访问数据库存储用户配置 |
| User → Config | 用户只能管理自己的列配置（通过 user_id 隔离） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-01 | Spoofing | API endpoints | mitigate | JWT 认证中间件验证用户身份，从 token 提取 user_id |
| T-27-02 | Tampering | Save/Reset requests | mitigate | 验证 user_id 匹配，用户只能修改自己的配置 |
| T-27-03 | Information Disclosure | GetConfig endpoint | mitigate | 查询条件强制包含 user_id，WHERE user_id = ? AND page_key = ? |
| T-27-04 | Denial of Service | 大量配置请求 | mitigate | Redis 缓存减少数据库压力，防抖限制前端请求频率 |
| T-27-05 | Elevation of Privilege | 跨用户配置访问 | mitigate | 数据库 UNIQUE 约束(user_id, page_key, column_key)，服务层强制 user_id 匹配 |
</threat_model>
