# 46-02-PLAN: 一键回滚机制 + 误修复监控

## 目标

实现 Phase 46 R5 半自动修复的后半段：7d 窗口内一键回滚（恢复 `ops_asset.user_id` 到 `pre_fix_user_id`）+ 误修复率监控（7d 滑动窗口 + SysNotice 告警）+ v1.17 milestone close 流程。覆盖 ROADMAP SC3、SC4、SC7。

## 锁定的 4 项关键决策

本计划必须显式落实以下决策（详见 `.planning/phases/46-r5/46-CONTEXT.md`）：

- **D-C1**: 回滚粒度 = 仅恢复 `ops_asset.user_id` 为 `pre_fix_user_id`（在 suggestion 表 applied 时持久化）
- **D-C2**: 回滚窗口期 = 固定 7d（`rollback_window_until = applied_at + 7 day`），超过 7d UI 不显示按钮但 DB 仍允许
- **D-C3**: 回滚强写 operlog，使用 `operlog.OperTypeReset=11`（语义"恢复到原值"）
- **D-C5**: 误修复率监控 = `rolled_back / applied` 7d 滑动窗口，超过 `asset.reconciliation.fix.mis_fix_threshold`（默认 0.01）→ SysNotice 告警
