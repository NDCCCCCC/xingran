## 3 个关键学习(供未来 phase 复用)

1. **partial unique index 防并发 Accept** — D-B4 partial unique index `uniq_fix_suggestion_pending_per_exception` + migration_199 idempotent 块,保证同一 exception_id 只允许 1 个 pending。SQLite 测试用源码扫描验证,PG 由 migration 兜底。

2. **7d 回滚窗口 UI 反馈** — 7d 倒计时分 3 段颜色:剩余 < 1d 红色紧急 / < 3d 橙色 / >= 3d 蓝色 / 已过 7d 灰色"已超 7d 窗口"。剩余按钮自动隐藏,DB 仍允许超窗回滚(强制审计留痕)。

3. **误修复率 1h 节流** — `lastBreachNotifiedAt` in-memory 状态机 + mutex 保护,避免同一 breach 持续期间 cron 每 10min 推送一次。1h 选取依据:误修复率是慢变量(7d 窗口),10min cron 1h 6 次推送没有信息增量。
