### Task 2: 配置 Table expandable 展开功能

<read_first>
- xingran-react-frontend/src/pages/operations/workstations/index.tsx (现有 Table 配置)
- Ant Design Table expandable 文档（了解 API）
</read_first>

<action>
修改工位页面的 Table 组件配置：

1. 找到 Table 组件的定义

2. 添加或修改 `expandable` 属性：
```typescript
<Table
  // 现有属性...
  columns={columns}
  dataSource={data}
  // 添加 expandable 配置
  expandable={{
    expandedRowRender: (record) => (
      <WorkstationDeviceTable
        workstationId={record.id}
        onDeviceChange={() => {
          // 可选：刷新数据或更新状态
          fetchWorkstations();
        }}
      />
    ),
    rowExpandable: (record) => true, // 所有行都可展开
    expandIcon: ({ expanded, onExpand, record }) => (
      <Button
        type="text"
        size="small"
        onClick={(e) => onExpand(record, e)}
        style={{ fontSize: '12px' }}
      >
        {expanded ? '收起设备' : '查看设备'}
      </Button>
    ),
  }}
/>
```

3. 如果需要懒加载优化：
```typescript
const [expandedRowKeys, setExpandedRowKeys] = useState<React.Key[]>([]);

<Table
  expandable={{
    expandedRowRender: (record) => (
      <WorkstationDeviceTable
        workstationId={record.id}
        onDeviceChange={() => fetchWorkstations()}
      />
    ),
    rowExpandable: (record) => true,
    expandedRowKeys,
    onExpandedRowsChange: (keys) => setExpandedRowKeys(keys),
    expandIcon: ({ expanded, onExpand, record }) => (
      <Button
        type="text"
        size="small"
        onClick={(e) => onExpand(record, e)}
      >
        {expanded ? '收起设备' : '查看设备'}
      </Button>
    ),
  }}
/>
```
</action>

<acceptance_criteria>
- Table 包含 expandable 配置
- expandedRowRender 返回 WorkstationDeviceTable 组件
- 展开/收起功能正常工作
- 设备表格正确显示在展开行中
</acceptance_criteria>
