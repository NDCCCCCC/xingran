<read_first>

- internal/api/v1/operations/asset_handler.go (参考 CRUD 操作模式)
</read_first>

<action>
创建文件 `internal/api/v1/operations/workstation_device_handler.go`：

1. 定义 `WorkstationDeviceHandler` 结构：
```go
type WorkstationDeviceHandler struct {
    service operations.WorkstationDeviceService
}
```

2. 实现 `NewWorkstationDeviceHandler` 构造函数：
```go
func NewWorkstationDeviceHandler(service operations.WorkstationDeviceService) *WorkstationDeviceHandler
```

3. 实现以下 Handler 方法（遵循项目模式）：
   - `GetByWorkstation(c *gin.Context)` - GET /workstation-device/:workstationId
     - 从路径参数获取 workstationId
     - 验证 UUID 格式
     - 调用 service.GetDevicesByWorkstation
     - 返回 response.Success(data)
   
   - `AddManual(c *gin.Context)` - POST /workstation-device/manual
     - 绑定请求体（包含 device_serial, workstation_id 等）
     - 验证必填字段
     - 调用 service.AddDeviceManual
     - 返回 response.Success(created_device)
   
   - `SyncAD(c *gin.Context)` - POST /workstation-device/sync-ad
     - 从请求体获取 workstation_id
     - 调用 service.SyncFromAD
     - 返回 response.Success(result)
   
   - `SyncAsset(c *gin.Context)` - POST /workstation-device/sync-asset
     - 从请求体获取 workstation_id
     - 调用 service.SyncFromAsset
     - 返回 response.Success(result)
   
   - `Update(c *gin.Context)` - POST /workstation-device/:id/update
     - 从路径获取设备 ID
     - 绑定更新请求体
     - 调用 service.UpdateDevice
     - 返回 response.Success()
   
   - `Delete(c *gin.Context)` - POST /workstation-device/:id/delete
     - 从路径获取设备 ID
     - 调用 service.DeleteDevice
     - 返回 response.Success()
   
   - `SetPrimary(c *gin.Context)` - POST /workstation-device/:id/set-primary
     - 从路径获取设备 ID
     - 调用 service.SetPrimaryDevice
     - 返回 response.Success()

4. 使用 `response.Success()` 和 `response.Error()` 包装响应
5. 从 `c.Request.Context()` 传递 context
</action>

- internal/api/v1/operations/asset_router.go (参考 CRUD 路由模式)
</read_first>

<action>
创建文件 `internal/api/v1/operations/workstation_device_router.go`：

1. 定义 `SetupWorkstationDeviceRouter` 函数：
```go
func SetupWorkstationDeviceRouter(r *gin.RouterGroup, core *core.Core)
```

2. 在函数内部：
   - 创建 service 实例：`service := operations.NewWorkstationDeviceService(core.GetDB())`
   - 创建 handler 实例：`handler := operations.NewWorkstationDeviceHandler(service)`
   - 定义路由组：`deviceRouter := r.Group("/workstation-device")`
   
3. 注册路由（遵循项目约定）：
   - `deviceRouter.GET("/:workstationId", handler.GetByWorkstation)` - 查询工位设备
   - `deviceRouter.POST("/manual", handler.AddManual)` - 手动添加设备
   - `deviceRouter.POST("/sync-ad", handler.SyncAD)` - 同步 AD 设备
   - `deviceRouter.POST("/sync-asset", handler.SyncAsset)` - 同步资产设备
   - `deviceRouter.POST("/:id/update", handler.Update)` - 更新设备
   - `deviceRouter.POST("/:id/delete", handler.Delete)` - 删除设备
   - `deviceRouter.POST("/:id/set-primary", handler.SetPrimary)` - 设置主设备

4. 确保路由路径与前端 API 调用一致
</action>

1. **API 可访问性**:
   - 所有端点返回 200 状态码（正常情况）
   - 无效请求返回适当的错误码（400, 404, 500）

2. **数据验证**:
   - UUID 参数验证生效（无效 UUID 返回错误）

   - 添加接口创建设备记录
   - 更新接口修改设备信息
   - 删除接口软删除设备
   - 同步接口正确调用服务层
