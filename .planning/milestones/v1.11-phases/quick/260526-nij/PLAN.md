# 修复用户管理页面部门路径显示

## 问题描述

用户管理页面的部门列只显示最后一层部门名称，需要显示从二级部门开始的完整路径。

**示例：**
- 当前显示：`基础运维科`
- 期望显示：`分公司本部/科技创新部/基础运维科`

## 技术方案

### 后端修改

1. **在 `User` 模型中添加新字段** `deptPath` 用于存储完整部门路径
2. **修改用户列表查询逻辑**：
   - 利用 `Department` 模型的 `ancestors` 字段（包含祖先ID路径）
   - 查询所有祖先部门并构建完整路径
   - 从二级部门开始拼接（跳过顶级部门）

### 前端修改

1. **更新 `User` 类型**：添加 `deptPath` 字段
2. **修改表格列渲染**：使用 `deptPath` 而非 `deptName`
3. **向后兼容**：当 `deptPath` 为空时回退到 `deptName`

## 实施步骤

1. 后端：添加 `deptPath` 字段到 User 模型的 JSON 输出
2. 后端：实现部门路径构建逻辑
3. 前端：更新 User 类型定义
4. 前端：修改用户管理页面部门列显示
5. 测试验证

## 约束条件

- 保持向后兼容性
- 不影响现有 API 契约
- 遵循项目 Handler-Service 模式
- 使用 response.Success() 包装响应
