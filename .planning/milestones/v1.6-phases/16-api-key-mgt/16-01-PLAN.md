## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-16-01 | Spoofing | API Key 验证 | mitigate | 密钥格式严格验证（rec_ + 64位hex），防止伪造密钥 |
| T-16-02 | Tampering | API Key 模型 | mitigate | 使用 UUID 主键，密钥值存储在数据库中，防止篡改 |

| T-16-06 | Elevation of Privilege | 权限验证 | mitigate | 作用域验证（scopes 字段），支持权限继承检查 |
