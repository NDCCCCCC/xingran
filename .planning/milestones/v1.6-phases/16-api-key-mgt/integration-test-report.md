#### 失败原因分析

**主要问题:**
1. **错误包装不一致** - 服务返回的错误在某些情况下为 `nil`
   - 影响: 测试中的错误断言失败
   - 示例: "用户不存在" 测试期望包含 "用户不存在" 的错误，但得到 `nil`

2. **SQLite 唯一约束冲突** - 测试使用相同的密钥值
   - 影响: 多个测试尝试插入相同的密钥值导致 UNIQUE constraint failed
   - 根因: 测试数据未正确隔离

3. **数据库事务回滚** - 测试间未正确清理数据
   - 影响: 前一个测试的数据影响后续测试
   - 根因: 缺少事务回滚机制

// 在 apikey_service.go 中
func (s *apikeyService) CreateAPIKey(ctx context.Context, req *CreateAPIKeyRequest) (*APIKey, error) {

    if err := s.db.WithContext(ctx).Where("id = ?", req.UserID).First(&user).Error; err != nil {
        if errors.Is(err, gorm.ErrRecordNotFound) {
            return nil, fmt.Errorf("用户不存在")

        return nil, err
    }
