   - PerMinute int: 每分钟限制
   - PerHour int: 每小时限制
   - PerDay int: 每天限制

2. 定义 rateLimitWindow 结构：
   - minute []time.Time: 分钟级窗口
   - hour []time.Time: 小时级窗口
   - day []time.Time: 天级窗口
   - mu sync.Mutex: 互斥锁

3. 定义 RateLimiter 结构：
   - windows sync.Map: 并发安全的窗口映射
   - limits map[string]RateLimit: 作用域限制配置

4. 实现 NewRateLimiter 构造函数：
   - 初始化 limits 映射
   - 配置默认限制：
     - "read": {30, 500, 5000}
     - "write": {100, 1500, 15000}
     - "admin": {200, 5000, 50000}

   - 参数：key string, scope string
   - 返回：(bool, *RateLimitResult)
   - 获取或创建窗口
   - 加锁处理
   - 清理过期条目（早于1分钟、1小时、24小时）

   - 如果超限：返回 false 和剩余信息

   - ResetAt time.Time: 重置时间
   - Limit int: 限制总数

   - 返回 *rateLimitWindow

8. 实现 cleanOlderThan 函数（私有）：
   - 过滤时间切片，移除早于指定时间的条目
   - 返回清理后的切片

9. 实现 calculateRemaining 函数（私有）：
   - 计算剩余请求数（最小值）

10. 实现 calculateReset 函数（私有）：

创建 internal/middleware/apikey.go 文件，实现 API Key 认证中间件：

1. 实现 MultiAuth 中间件：
   - 参数：apiKeyService systemServices.APIKeyService, usageLogger services.UsageLogger
   - 返回：gin.HandlerFunc
   - 提取 X-API-Key 请求头
   - 如果为空，跳过 API Key 验证（允许 JWT 认证）
   - 验证密钥格式（isValidKeyFormat）
   - 调用 apiKeyService.ValidateAPIKey
   - 如果验证失败：返回 401 错误
   - 如果验证成功：
     - 设置用户上下文（user_id, username, roles, scopes）
     - 设置认证类型（auth_type = "api_key"）
     - 异步记录使用日志（usageLogger.LogUsage）
   - 调用 c.Next()

2. 实现 extractAPIKey 函数（私有）：
   - 从 X-API-Key 请求头提取
   - 如果不存在，返回空字符串

3. 实现 isValidKeyFormat 函数（私有）：
   - 检查前缀 "rec_"
   - 检查长度 68（4 + 64）
   - 检查十六进制格式

4. 实现 isIPAllowed 函数（私有）：
   - 参数：clientIP string, whitelist []string
   - 返回：bool
   - 如果白名单为空，返回 true
   - 解析客户端 IP（net.ParseIP）
   - 遍历白名单：
     - 包含 "/"：解析 CIDR，检查包含
     - 不包含 "/"：精确匹配
   - 返回是否匹配

5. 实现 setUserContext 函数（私有）：
   - 设置 c.Set("user_id", userID)
   - 设置 c.Set("username", username)
   - 设置 c.Set("roles", roles)
   - 设置 c.Set("scopes", scopes)
   - 设置 c.Set("auth_type", "api_key")

参考 auth.go 的 JWT 验证模式
使用 response.Error 返回错误
中间件文件放在 internal/middleware/ 目录下
