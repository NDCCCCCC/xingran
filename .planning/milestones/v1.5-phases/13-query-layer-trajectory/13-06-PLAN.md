## Objective

## Background

3. **CR-03**: Missing MAC Address in TrajectoryNode - 响应结构缺少 MAC 地址字段

详见 `.planning/phases/13-query-layer-trajectory/13-VERIFICATION.md` 和 `13-REVIEW.md`。

### Task 6: Fix OUI Import Race Condition (WR-05)

**File:** `internal/services/mac_history_query_service.go`

**Action:** 使用 INSERT ... ON CONFLICT DO NOTHING 防止重复导入

**Current (WRONG):**
```go
// Check if table has data
var count int64
if err := s.db.WithContext(ctx).Table("sys_mac_oui_vendor").Count(&count).Error; err != nil {
    return fmt.Errorf("failed to check OUI table: %w", err)
}
if count > 0 {
    applogger.Infof("OUI table already has %d records, skipping import", count)
    return nil
}
// ✗ Race: Another instance could insert data here
// Import data
data, err := os.ReadFile("configs/oui-vendors.json")
// ... insert operations
```

**Target (CORRECT):**
```go
// Use INSERT ... ON CONFLICT DO NOTHING
batch := vendors[i:end]
if err := s.db.WithContext(ctx).
    Clause(clause.OnConflict{DoNothing: true}).
    Create(&batch).Error; err != nil {
    return fmt.Errorf("failed to insert OUI batch %d: %w", i/batchSize, err)
}
```

**Sub-tasks:**
6.1. 移除 count > 0 检查（避免 check-then-act race）
6.2. 在批量插入添加 `Clause(clause.OnConflict{DoNothing: true})`

## Notes

- **API Contract 决策**: 保持后端 camelCase 约定，调整前端匹配。理由：Go 标准库 `encoding/json` 默认 camelCase，项目其他 API 已遵循此约定。
- **React 输入处理**: 选择 controlled component 而非 uncontrolled + ref，理由：项目 React Query 架构偏好受控组件模式。
- **TopN 限制值**: 选择 1000 作为上限，理由：Gantt 图超过 1000 节点已无法清晰渲染，更大值无实际意义。
- **厂商查询集成**: POST 请求优于 GET，理由：查询参数可能超过 URL 长度限制（虽当前 OUI 仅 6 字符，但预留扩展性）。
