## Interaction Patterns

### Batch Export Flow

1. **Trigger**: User clicks "批量导出" button in network management page toolbar
2. **Selection**: Modal opens with checkboxes for all 9 entity types (all pre-selected by default)
3. **Confirmation**: User clicks "确认导出 (N)" button (N = number of selected entity types)
4. **Processing**: Button shows loading state, modal remains open with backdrop
5. **Completion**:
   - Success: Message "批量导出成功", modal closes, ZIP file downloads
   - Error: Message "批量导出失败：{error}", modal remains open

### State Management

| State | Visual Indicator |
|-------|-----------------|
| Idle | "批量导出" button enabled when `selectedRowKeys.length > 0` |
| Loading | "批量导出" button disabled, modal shows `confirmLoading` |
| Success | `message.success()`, ZIP download triggered |
| Error | `message.error()`, error details displayed |

### Data Limits

- Maximum records per entity: 10,000 (enforced backend)
- Maximum ZIP size: 100MB (enforced backend)
- If exceeded: Error message "数据量过大，请缩小筛选范围后重试"

## Developer Notes

### Implementation Approach

**Backend (Go):**
- New endpoint: `POST /api/v1/network/batch-export`
- Request body: `{ entityTypes: string[], filters: Record<string, any> }`
- Response: ZIP file stream with `Content-Disposition: attachment; filename="网络管理_批量导出_{timestamp}.zip"`
- Use `archive/zip` package to bundle Excel files
- Reuse existing export functions from `network_export_handler.go`

**Frontend (TypeScript):**
- New component: `BatchExportModal.tsx` in `src/components/shared/`
- Props: `visible`, `onConfirm`, `onCancel`, `loading`, `availableEntityTypes`
- Integration: Add "批量导出" button to all 9 network management pages
- Use Ant Design `Checkbox.Group` for entity type selection
- Download handling: Create blob URL from ZIP response, trigger download

**Component Structure:**
```tsx
<BatchExportModal
  visible={batchModalVisible}
  onConfirm={handleBatchExport}
  onCancel={() => setBatchModalVisible(false)}
  loading={batchExporting}
  availableEntityTypes={[
    { key: 'devices', label: '网络设备' },
    { key: 'credentials', label: '授权凭证' },
    // ... 7 more types
  ]}
/>
```
