每个方法的 panic 恢复包装器必须：
1. 在方法开头添加 defer func() { if r := recover(); r != nil { ... } }()
2. 使用 debug.Stack() 捕获完整堆栈跟踪
3. 记录设备标识：从 c.client.Target 提取 IP 地址
4. 记录操作上下文：方法名 (Get/GetNext/Walk/GetBulk)
5. 记录 panic 值和时间戳
6. 使用 applogger.Errorf 记录 ERROR 级别日志
7. 将 panic 转换为 error 返回，使用 fmt.Errorf("SNMP {METHOD} panic: %v", r)
8. 关闭连接防止复用：调用 c.Close()

日志格式：
```go
applogger.Errorf("[SNMP] Panic: ip=%s, method=%s, error=%v, stack=%s",
    c.client.Target, methodName, r, string(debug.Stack()))
```

返回错误格式：
```go
return [zero value], fmt.Errorf("SNMP %s操作panic: %v", methodName, r)
```

- runtime/debug (用于 debug.Stack())
- github.com/xingran-next/xingran-go-backend/pkg/logger (用于 applogger)

保持现有错误处理逻辑不变，仅在 panic 恢复中添加新逻辑。
