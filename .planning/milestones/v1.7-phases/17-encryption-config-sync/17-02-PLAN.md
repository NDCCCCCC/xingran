<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser→API | Untrusted browser environment can cache config values |
| API→Browser | Backend API response may be intercepted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-05 | Spoofing | Frontend cache in memory | accept | Cache is memory-only (resets on page refresh), tampering causes request failures not security breaches |
| T-17-06 | Tampering | Config response during transit | mitigate | HTTPS in production, TypeScript validation, default to "enabled" on errors |
| T-17-07 | Information Disclosure | Error messages expose config | accept | Config is non-sensitive boolean, errors logged locally only |
| T-17-08 | Denial of Service | Excessive config API calls | mitigate | 5-minute cache reduces calls by 99%, backend has 30-second cache |

**Security Considerations:**
- Frontend cache is ephemeral (memory-only), no persistent storage
- Failed config fetch defaults to "enabled" (fail-safe for security)
- Cache TTL (5 min) > backend TTL (30 sec) ensures backend is authoritative
- Type validation via TypeScript interface prevents injection attacks
</threat_model>
