## 📋 规划概述

### 核心目标
实现系统部门与AD域控OU的双向映射功能，建立完整的组织架构同步机制。

### 三大核心功能
1. **部门定时同步** (系统 → AD): 每天凌晨2点自动同步部门树到AD OU
2. **用户登录部门设置** (AD → 系统): AD认证时通过OU反向查找设置部门
3. **用户修改AD同步** (系统 → AD): 修改用户信息时同步到AD域控
