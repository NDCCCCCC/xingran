## 1. 修改 GetConnection 路径 — existing connection 分支

定位: `connection_pool.go:207-215`

修改前:
```go
if exists {
    if pc.wrapper != nil && pc.wrapper.IsReady() {
        deviceLock.Unlock()
        return pc, nil   // RACE: caller 拿到 pc 后才 Acquire,中间 cleanup 可能关闭
    }
    // ...
}
```

修改后:
```go
if exists {
    if pc.wrapper != nil && pc.wrapper.IsReady() {
        // F-14 fix: 在持有 deviceLock 时直接 +1 refCount,
        // 阻止 cleanup goroutine 在 unlock 与 caller-use 之间关闭连接。
        // refCount > 0 是 cleanupIdleConnections 跳过的条件。
        atomic.AddInt32(&pc.refCount, 1)
        pc.lastUsed = time.Now()
        deviceLock.Unlock()
        return pc, nil
    }
    // 连接失效,从池中移除
    // ... (保持不变)
}
```

## 2. 修改 GetConnection 路径 — new connection 分支

定位: `connection_pool.go:262-280`

修改前:
```go
pc = &PooledConnection{
    wrapper:  wrapper,
    refCount: 0,
    lastUsed: time.Now(),
    deviceID: deviceID,
    mu:       deviceLock,
    pool:     p,

// 添加到池中
```

修改后:

```go
pc = &PooledConnection{
    wrapper:  wrapper,
    refCount: 1, // F-14 fix: 直接初始化为 1,表示已有 GetConnection 调用方持有
    lastUsed: time.Now(),
    deviceID: deviceID,
    mu:       deviceLock,
    pool:     p,
}
// 添加到池中

p.connections[deviceID] = pc

deviceLock.Unlock()
return pc, nil
```
