在 apikey_service.go 中实现密钥生成和验证功能：

1. 实现 generateKey 函数（私有）：
   - 使用 crypto/rand 生成 32 字节随机数
   - 转换为 64 位十六进制字符串（encoding/hex）
   - 添加前缀 "rec_"
   - 返回密钥字符串和错误

2. 实现 ValidateAPIKey 方法：
   a. 验证密钥格式：
      - 检查前缀是否为 "rec_"
      - 检查长度是否为 68（4 + 64）
      - 检查后 64 位是否为有效十六进制
   b. 查询数据库：
      - 查询条件：key = ?, is_active = true, deleted_at IS NULL
      - 预加载用户信息（Preload User）
   c. 验证过期时间：
      - 如果 expires_at 不为空且早于当前时间，返回错误
   d. 更新最后使用时间（异步，使用 goroutine）
   e. 返回 APIKey 对象

3. 实现 isKeyExpired 函数（私有）：
   - 参数：*time.Time
   - 返回：bool（true=已过期）

4. 实现 isValidKeyFormat 函数（私有）：
   - 参数：string
   - 返回：bool（true=格式正确）
   - 检查前缀和十六进制格式
