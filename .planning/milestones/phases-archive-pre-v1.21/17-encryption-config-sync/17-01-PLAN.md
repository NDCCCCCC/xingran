| T-17-03 | Tampering | Config response in transit | mitigate | Production uses HTTPS, frontend validates response format against TypeScript interface |
| T-17-04 | Spoofing | Man-in-the-middle alters config response | mitigate | HTTPS + frontend is memory-only cache (resets on page refresh), no persistent tampering possible |

**Security Considerations:**
- Encryption config is non-sensitive (similar to captcha config), public endpoint is safe
- Cache poisoning mitigated by memory-only storage and short TTL
- Failed config queries default to "enabled" (more secure)
