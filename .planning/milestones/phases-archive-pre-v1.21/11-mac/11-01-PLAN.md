# Interface Name Normalization (from portcollection/utils.go)

**CRITICAL:** LLDP discovery must return normalized interface names as map keys to ensure successful lookups in MAC collection filtering. The MAC collection service will normalize interface names from MAC tables before looking them up in the LLDP neighbor map. If LLDP returns raw names like "GigabitEthernet0/1" but MAC table has "gi0/1", the lookup will fail.

Use this normalization function (reused from portcollection):

```go
func normalizeInterfaceName(name string) string {
    name = strings.ToLower(name)

    replacer := strings.NewReplacer(
        "gigabitethernet", "gi",
        "fastethernet", "fa",
        "tengigabitethernet", "te",
        "ethernet", "eth",
        "hundredgig", "hundredgige",
        "fortygig", "fortygige",
        "twenty-fivegig", "twenty-fivegige",
        "/", "",
        " ", "",
    )

    return replacer.Replace(name)
}
```

# Template Cache Pattern (from PATTERNS.md)

Reuse template cache pattern from portcollection:

```go
type TemplateCache struct {
    cache map[string]*templates.FSM
    mu    sync.RWMutex
}

func (c *TemplateCache) Get(templatePath string) (*templates.FSM, error) {
    c.mu.RLock()
    fsm, ok := c.cache[templatePath]
    c.mu.RUnlock()

    if ok {
        return fsm, nil
    }

    c.mu.Lock()
    defer c.mu.Unlock()

    // Double-check
    fsm, ok = c.cache[templatePath]
    if ok {
        return fsm, nil
    }

    // Load and cache template
    fsm, err := templates.ParseTemplate(templatePath)
    if err != nil {
        return nil, err
    }

    c.cache[templatePath] = fsm
    return fsm, nil
}
```
