    5. 实现 `(*macHistoryQueryServiceImpl).QueryMACTrajectory`：
       - 先调 `validateMACAddress(req.MACAddress)`，否则 error 返回。
       - 解析 `StartTime`/`EndTime`（RFC3339），无值则用 now-30d ~ now 默认；跨度 ≤ 1 年 DoS 保护（**复用 line 99 `maxQueryRange` 常量**，不是新声明）。
       - 单条 `s.db.WithContext(ctx).Raw()` 调 LAG 窗口函数：
         ```sql
         SELECT id, device_id, device_name_snapshot, mac_address,
                interface_name, vlan_id, event_type,
                first_seen, last_seen,
                LAG(interface_name) OVER w AS prev_interface,
                LAG(vlan_id)       OVER w AS prev_vlan,
                LAG(first_seen)    OVER w AS prev_first_seen,
                LAG(device_id)     OVER w AS prev_device_id
         FROM sys_device_mac_history
         WHERE mac_address = ?
           AND first_seen >= ? AND first_seen <= ?
         WINDOW w AS (PARTITION BY mac_address ORDER BY first_seen)
         ORDER BY first_seen ASC
         ```
         注意：所有 WHERE 条件在窗口函数之前执行（D-13-1.1 + RESEARCH.md Pitfall 1），接受 LAG 返回 NULL 的首条记录。
       - 应用层 `AggregateTrajectory(rawEvents)`：按 (DeviceID, InterfaceName, VLANID) 复合键合并连续状态；每组取 MIN(first_seen) ~ MAX(last_seen)；计算 `Duration = EndTime.Sub(StartTime).Seconds()` int64 秒。
       - 返回 `&MACTrajectoryResult{MACAddress: req.MACAddress, Nodes: nodes}`。

    6. 添加单元测试 `mac_history_query_service_test.go`：
       - `TestValidateMACAddress` — 表驱动（合法/非法/带分隔符）。

       // @Summary 查询MAC地址移动轨迹
       // @Description 按MAC地址查询跨设备/端口的移动路径，返回按时间排序的轨迹节点

       // @Param request body mac_history_query_service.MACTrajectoryQuery true "查询条件"
       // @Success 200 {object} response.Response{data=mac_history_query_service.MACTrajectoryResult}
       // @Failure 400 {object} response.Response
       // @Failure 500 {object} response.Response
       // @Router /network/history/trajectory [post]
       func (h *MACHistoryHandler) QueryTrajectory(c *gin.Context) {
           var req mac_history_query_service.MACTrajectoryQuery
           if !responseHelpers.HandleJSONBinding(c, &req) {
               return

           result, err := h.historyQueryService.QueryMACTrajectory(c.Request.Context(), &req)

               return
           }
           response.Success(c, result)
       }
