## Goal

把 `brand-spec.md` 的像素实测品牌令牌（深绿 `#156031` × 铜金 `#C09058` × 奶油 `#F0ECE3`）固化进 design-system 层：253 个 CSS 变量值对齐品牌实测、TS 侧新增 `xingranBrand` 常量作为唯一真相源、Antd 6 `theme.token` + `theme.components` 全量映射到品牌令牌、shadows/spacing/typography 与新色彩调性对齐；并以可执行的 vitest 对比度校验断言关键前景/背景对达标，把品牌基线锁在测试层。
