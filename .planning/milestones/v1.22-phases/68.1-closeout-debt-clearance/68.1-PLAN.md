## 事实核查注记（planner 实测，executor 须知）

1. **`src/components/shared/confirmDelete.ts` 现状无「提交中禁取消 / maskClosable / keyboard / focusable / aria-busy」**：`Modal.confirm` 参数只有 `title / content / okText / cancelText / okButtonProps / onOk`（`:34-40`）。`okButtonProps` 是静态对象，**提交中动态禁取消按钮**必须用 `Modal.confirm` 返回实例的 `update()`——仓库已有同款写法（`src/pages/operations/buildings/index.tsx:445` 的 `confirmInstance.update`）。这是 T1 的核心实现约束。
2. **`ConfirmDelete.tsx:40` 当前 `aria-label={typeof title === "string" ? title : "删除"}`**：经 `createDeleteAction`（`ActionButtons.tsx:136-147`）传入 `DELETE_CONFIRM.title`（= `"确认删除"`）后，实际可访问名是「确认删除」——既非动作名也不含对象名。Q1 要求改为 `删除${target}`。
3. **`BatchDeleteButton.tsx:50` 的 target 是硬编码** `` `选中的 ${selectedCount} 项` ``；`PageTable.tsx:60` 已声明 `batchDelete.target: string` 但 `:247-249` 渲染时未传 → minor #2 根因。**`target` 语义 = 对象类别**（如 `"资产"` / `"岗位"`），最终文案为 `选中的 {N} 项{target}`；缺省时保持 `选中的 {N} 项` 不变。既有消费方 `src/pages/system/post/index.tsx:211-217`（`target: "岗位"`）因此从「选中的 3 项」变为「选中的 3 项岗位」——属 §8-5 期望的**文案改善**，不是回归。
4. **`FormModal.tsx` 的 `FormModalProps`（`:33-49`）无 `maskClosable` / `keyboard` 透传位**；`BaseEditModal.tsx:40-65` 已有 `maskClosable = false` / `keyboard = false` 默认值并已透传（`:62-63`）。补透传位时**默认值必须沿用 `false`/`false`**（Phase 64 FIX-02 口径，不放松）。
5. **两个生成脚本只写 `eslint.config.js` 的锚点 `files` 数组**（`gen-p65-exemptions.mjs` 锚点 `:27` / 写回 `:110-114`；`gen-p66-exemptions.mjs` 锚点 `:31` / 写回 `:111-115`），命中判定靠 `message` 前缀匹配。→ **理由清单放在 `xingran-react-frontend/scripts/` 下（新文件）即天然不被触碰**（Q3 落地依据）。
6. **P66 的 41 条豁免全部因为 `import usePagination / useTableManager`**（both 17 / 仅 usePagination 23 / 仅 useTableManager 1 = `src/pages/monitor/logs/index.tsx` / antd 子包命中 0）。**收缩 P66 的唯一正确路径是「把页面迁到 PageTable 让 import 消失」**，不是改 rules。
7. **`src/pages/monitor/cache/index.tsx` 同时是「已迁 PageTable 的 5 页之一」又是 P65 命中文件**（Input+Select+Modal.confirm+Popconfirm 四类全中）→ 它在 T2/T3/T4 都可能被触及，T7 复扫时须核对它是否真的从清单里移出。
8. **`src/pages/system/menu/hooks/useMenuActions.tsx:242` 的批删含级联 checkbox**（`modalInstance.checkboxRef`）——`confirmDelete` 的 `extra` 位（`ReactNode`）可承载该 checkbox，但**级联语义是「级联删除子菜单」**，迁移时须把 checkbox 作为 `extra` 挂进确认弹窗并保持默认值与文案，不得静默丢失级联选项。
