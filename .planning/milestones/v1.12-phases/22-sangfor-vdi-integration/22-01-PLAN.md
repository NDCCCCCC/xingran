### Key Design Decisions

1. **多VDI服务器支持**: 系统需要管理多个深信服VDI实例（如生产/测试环境）
2. **UUID外键约束**: `org_id`和`user_id`必须符合UUID格式验证（参考building_service.go模式）
3. **状态值约定**: 遵循0=正常/1=停用的项目约定
4. **SM4密码加密存储**: VDI服务器密码使用SM4加密存储（参考AD域模块utils.go中的encryptPassword/decryptPassword模式）
5. **Token缓存机制**: AuthToken和过期时间缓存在数据库中，避免频繁认证

   ```go
   package operations
   
   import (
       "crypto/aes"
       "crypto/cipher"
       "crypto/rand"
       "encoding/base64"
       "io"
   )
   
   // encryptVDIPassword 加密VDI服务器密码（使用AES-128-GCM）
   func encryptVDIPassword(password string) string {
       const encryptionKey = "xingran-vdi-server-key-16"
       key := []byte(encryptionKey[:16])
       
       block, err := aes.NewCipher(key)
       if err != nil {
           return password
       }
       
       gcm, err := cipher.NewGCM(block)
       if err != nil {
           return password
       }
       
       nonce := make([]byte, gcm.NonceSize())
       if _, err := io.ReadFull(rand.Reader, nonce); err != nil {
           return password
       }
       
       ciphertext := gcm.Seal(nonce, nonce, []byte(password), nil)
       return base64.StdEncoding.EncodeToString(ciphertext)
   }
   
   // decryptVDIPassword 解密VDI服务器密码
   func decryptVDIPassword(encrypted string) string {
       const encryptionKey = "xingran-vdi-server-key-16"
       key := []byte(encryptionKey[:16])
       
       data, err := base64.StdEncoding.DecodeString(encrypted)
       if err != nil {
           return encrypted
       }
       
       block, err := aes.NewCipher(key)
       if err != nil {
           return encrypted
       }
       
       gcm, err := cipher.NewGCM(block)
       if err != nil {
           return encrypted
       }
       
       nonceSize := gcm.NonceSize()
       if len(data) < nonceSize {
           return encrypted
       }
       
       nonce, cipherData := data[:nonceSize], data[nonceSize:]
       plaintext, err := gcm.Open(nil, nonce, cipherData, nil)
       if err != nil {
           return encrypted
       }
       
       return string(plaintext)
   }
   ```

## Threat Model

### Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Config → Database | VDI服务器密码从YAML到数据库的传输 |
| Application → VDI API | HTTP请求到深信服VDI服务器 |

### STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-01 | Tampering | VDI Server Config | mitigate | 使用AES-GCM加密存储VDI服务器密码（参考AD域模块utils.go），配置文件使用环境变量占位符，密钥长度16字节（AES-128） |
| T-22-02 | Information Disclosure | AuthToken字段 | mitigate | 数据库中使用`json:"-"`隐藏token，日志中脱敏处理 |
| T-22-03 | Spoofing | VDI API通信 | mitigate | 后续phase实现HSTS验证和证书pinning，当前phase记录风险 |
| T-22-04 | Denial of Service | 连接超时 | accept | 当前phase仅设置超时配置，实际重试机制在后续VDI客户端实现 |
