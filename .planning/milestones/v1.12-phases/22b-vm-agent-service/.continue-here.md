## 技术决策

1. **自动注册方案选择**
   - 决策: 使用后端 API + 指纹匹配
   - 理由: 支持模板批量部署，无需手动配置 ID
   - 影响: Agent 可自动识别虚拟机身份

2. **配置加载优先级**
   - 决策: 环境变量 > 配置文件 > 自动注册
   - 理由: 提供灵活性，支持多种部署场景
   - 影响: 配置管理更加灵活
