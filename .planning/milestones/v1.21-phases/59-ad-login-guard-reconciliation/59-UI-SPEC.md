## 页面结构与交互契约

### 嵌入位置（D-17 锁定）

修改 `xingran-react-frontend/src/pages/ad-domain/configs/index.tsx`：

```
<Card>
  <Tabs
    activeKey={activeTab}
    onChange={setActiveTab}
    items={[
      { key: "configs", label: "配置列表", children: <现有配置表格及工具栏> },
      { key: "reconciliation", label: "对账", children: <ReconciliationTab /> },
    ]}
  />
</Card>
```

- 现有配置表格（含新增/刷新/编辑/删除/详情 Drawer）整体下沉为第一个 Tab 的 children，逻辑不变。
- `activeTab` 用 `usePersistedStateController<string>` 持久化（`keyPrefix: location.pathname`，`keySuffix: "activeTab"`，默认 `"configs"`），与 `src/pages/system/settings-page/index.tsx` 同款。
- 不新增菜单 seed、不新增路由、不新建独立页面。

### 权限门（D-17 锁定）

```tsx
const permissions = useMenuStore((s) => s.permissions);
const canView = permissions.includes("ops:ad:config:reconciliation:list");
```

- Tab **始终可见**；无权限时 Tab 内容渲染 `<Result status="403" title="无对账查看权限" subTitle={...} />`，**不发任何请求**。
- 不得用「隐藏整个 Tab」替代；D-17 明文要求 Tab 内判定。

### 对账 Tab 内部布局

```
[筛选行]  不一致类型 Select | 部门 TreeSelect | 关键字 Input | [查询] [重置]
[工具栏]  [刷新]（可选，放在筛选行右侧或独立行；与查询按钮视觉区分）
[表格]    7 列，只读，分页
```

- 筛选行使用 `<Form layout="inline">` + `<Space size="middle">`，`marginBottom: 16`。
- 查询为显式提交：**不**在控件 onChange 时自动请求（避免每次输入触发全表扫描）。
- 重置后 `current` 回到 1 并立即查询。
- 翻页/改页大小后保持当前筛选条件。

### 表格列定义（7 列，只读）

| # | 列标题 | 数据源 | 宽度 | 渲染规则 |
|---|--------|--------|------|----------|
| 1 | 不一致类型 | `mismatchType` | 180 | Tag（语义色见上表）+ 中文标签 |
| 2 | 部门 | `deptName` | 180 | `deptDeletedAt` 非空时在名称后追加 `<Tag color="red">已删除</Tag>`；空值渲染 `-` |
| 3 | AD 配置 | `configName` | 150 | 空值渲染 `-` |
| 4 | 映射 OU | `mappedOuDn` | 260 | `ellipsis: true` + `Tooltip` 全文；空值 `-` |
| 5 | 用户 | `username` | 160 | 空值 `-`（部门级条目无用户） |
| 6 | 用户 OU | `userAdOuDn` | 260 | `ellipsis: true` + `Tooltip` 全文；空值 `-` |
| 7 | 详情 | `mismatchDetail` | 320 | `ellipsis: true` + `Tooltip` 全文 |

- **不展示**原始 UUID：`dept_id` / `ad_config_id` / `user_id` 不作为列；如需排障可放入部门/用户单元格的 `Tooltip`，但本 phase 不要求。
- **无操作列**、无排序（D-16 未提供排序参数）、无导出、无批量选择。
- `rowKey` 由组合键生成：`` `${mismatchType}-${deptId ?? ""}-${userId ?? ""}-${adConfigId ?? ""}` ``，保证部门级与用户级行唯一。
- `scroll={{ x: 1400 }}` 保证窄屏横向滚动。

### 分页

- 默认 `current: 1`，`pageSize: 20`。
- `showSizeChanger: true`，选项 `10 / 20 / 50 / 100`。
- `showTotal: (t) => \`共 ${t} 条\``。
- 与同模块 `AccountPoolTab` / `logs` 页保持一致（简单 `useState`，不引入 React Query）。

### 数据加载（遵循模块既有模式 + CLAUDE.md）

- 使用 `App.useApp()` 的 `message` 提示错误，不直接 `import { message } from "antd"`。
- `loadList` 用 `useCallback`，依赖为原始值（`current` / `pageSize` / 各筛选值），`useEffect` 依赖 `[current, pageSize, mismatchType, deptId, keyword]`；**禁止**把对象/数组放进依赖（CLAUDE.md useEffect 稳定性规则）。
- 请求失败：表格区域渲染 `ErrorAlertWithRetry`（`description="对账数据加载失败，请稍后重试。"`，`onRetry={loadList}`），不要同时弹多个 message。
- 请求成功且 `list.length === 0`：表格区域渲染 `EmptyStateWithAction`，不渲染空表头。
- 加载中：Table `loading`；翻页时保留旧数据直到新数据返回（若实现简单状态，可在请求期间仅显示遮罩，不强制 keepPreviousData）。

### 部门筛选

- 使用 `DepartmentTreeSelect`（`@/components/shared`），数据由 `useDeptTree()` 提供。
- 只作为筛选条件，不参与权限判断。
- 软删部门可能不在部门树中；此时用户可通过关键字搜索覆盖该场景（无需额外「包含已删除部门」开关）。
