# 快照语义（接线时最容易搞错的一点）

`Update` 里 `First(&user, ...)` 拿到的 `user` 在事务闭包内被**整体覆盖**（`user.Nickname = req.Nickname` 等是重新赋值指针，不是改写指针指向的值）。因此必须在 `First` 成功之后、事务闭包之前对 `user` 做一次**值拷贝**（`oldUserSnapshot := user`）作为 diff 旧值来源；否则传入的"旧值"就是新值，diff 永远返回 false。

- **D-02 第二层**：入队返回 error 必须 `return err`（包 `apperrors.DatabaseError`），让 `tx.Commit()` 不执行。**禁止**"捕获错误只打 WARN 然后 return nil"
- **D-03**：不得删除/修改 `internal/api/v1/system/user_handler.go:194-238` 的旧推送路径（`adSyncInFlight` / `buildADSyncMap` / goroutine + 3 次重试），它随 Phase 58 排水器同二进制删除；本 plan 不碰 handler 层
- operlog 约定（CLAUDE.md）：service 层不调 operlog，Delete / BatchDelete 的操作日志仍由 handler 既有 `operlog.Record` 承担
- 入队调用点必须在事务闭包体内、`return nil` 之前；不得放到闭包外、不得 goroutine、不得 defer
