# 表结构契约（三个 plan 共用，不得改动）

| 列 | PG 类型 | sqlite 类型 | 说明 |
|----|---------|------------|------|
| id | uuid PRIMARY KEY | `uuid PRIMARY KEY` | BeforeCreate 生成，防 23502 |
| entity_type | varchar(32) NOT NULL | 同 | 值固定 `"user"` |
| entity_id | varchar(64) NOT NULL | 同 | **varchar 而非 uuid**：sys_user.dept_id 是 varchar(64)，跨实体类型混用；sqlite 下 `uuid` declType 也会踩 affinity 坑 |
| action_type | varchar(32) NOT NULL | 同 | `"update_user"` / `"disable"` |
| status | varchar(20) NOT NULL DEFAULT 'pending' | 同 | pending/failed/pushed/dead |
| attempts | integer NOT NULL DEFAULT 0 | 同 | Phase 58 退避用（D-07） |
| next_retry_at | timestamptz | **datetime** | Phase 58 退避扫描用 |
| last_error | text | text | Phase 58 写入 |
| created_at / updated_at | timestamptz | **datetime** | |
| pushed_at / failed_at | timestamptz | **datetime** | 可空终态列 |

**时间列为何方言不同**：`github.com/glebarez/go-sqlite@v1.21.2/sqlite.go:445` 只在 declType 为 `date|datetime|time|timestamp` 时把列扫成 `time.Time`；写 `timestamptz` 会扫成 string 并在 Scan 到 `*time.Time` 时报错。故 CREATE TABLE 必须 `isPostgreSQL(db)` 分方言，索引 DDL 双方言共用。
