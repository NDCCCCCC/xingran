# Requirements

## v1.1 Requirements

### 导入配置
- [x] **IMPORT-05**: Excel 导入配置添加"所属设备"列，通过设备名称匹配 `sys_network_device.name`，写入 `device_id`
- [x] **IMPORT-06**: Excel 导入配置添加"所属端口"列，通过端口名称匹配 `sys_device_port_status.port_name`，写入 `port_id`
- [x] **IMPORT-07**: 两个字段均为可选，匹配失败时留空不阻断导入

### 验证
- [x] **VAL-03**: 导入含设备名/端口名的 Excel 后，信息点列表正确显示设备名称和端口名称
- [x] **VAL-04**: 导出包含设备和端口信息（已有，验证不退化）

## v1.0 Requirements (Completed)

- [x] **IMPORT-01**: Excel 导入配置添加"所属部门"列
- [x] **IMPORT-02**: Excel 导入配置添加"所属用户"列
- [x] **IMPORT-03**: 两个字段均为可选，匹配失败时留空不阻断导入
- [x] **IMPORT-04**: Excel 导出包含"所属部门"和"所属用户"列

- [x] **VAL-02**: 导入不含部门/用户名的 Excel 后，工位列表对应列为空

## v2 Requirements (Deferred)

- 信息点导入时通过楼宇+楼层级联匹配工位（解决需要知道工位名的问题）
- 导入时显示匹配失败的警告信息

## Out of Scope

- 设备/端口多对多关系 — 当前只需一对一
- 导入时自动创建不存在的设备或端口 — 超出导入功能职责
- 端口与设备的级联验证（确认端口属于指定设备）— 复杂度高，用户未要求
