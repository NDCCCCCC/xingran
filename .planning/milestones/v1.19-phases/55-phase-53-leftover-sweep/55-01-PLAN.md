**read_first:**

- `.planning/phases/53-w4-frontend-drawer-progress-dialog-api-wrappers/53-REVIEW.md` (line 153-176: WR-02 原始描述与修复方向)

**action:**

将 `composeReason` / `validateReasonOptional` / `validateReasonRequired` 三个 helper 从 `PortWriteModal.tsx` 抽出,放到 `constants.ts` 文件尾部(放在 `DESCRIPTION_MAX` 常量之后,文件 line 68 之后),导出形式保持不变:

- `composeReason(reasonSelect, reasonText): string | null` — 纯函数,无 React 依赖。
- `validateReasonOptional(rule, value, form): Promise<void>` — 接收 `(rule, value, form)` 三个参数,**修正签名**(原签名错接收 `reasonSelect/reasonText` 参数实际拿不到值),改用 `form.getFieldValue("reasonText")` 跨字段取值(等价于 `Form.useWatch` 的非 hook 版本)。
- `validateReasonRequired(rule, value, form): Promise<void>` — 同上,签名修正 + form 参数。

签名修正理由: antd validator 只传 `(rule, value)` 两个参数,原代码期望 `(_, reasonSelect, reasonText)` 第三参数 `reasonText` 永远是 `undefined`,custom-reason 的 `REASON_MIN=5` 下限校验彻底失效。修复后从 `form` 参数(`form` 是 Form instance,可调用 `form.getFieldValue("reasonText")`)读取跨字段值,绕过 antd 调用约定不传跨字段值的限制。

导出语句(在 constants.ts 末尾追加):

```typescript
import type { FormInstance } from "antd";

export const REASON_CUSTOM_SENTINEL = "__custom__";

export function composeReason(reasonSelect: unknown, reasonText: unknown): string | null {
  if (reasonSelect === REASON_CUSTOM_SENTINEL) {
    const text = typeof reasonText === "string" ? reasonText.trim() : "";
    return text.length > 0 ? text : null;
  }
  return typeof reasonSelect === "string" && reasonSelect.length > 0 ? reasonSelect : null;
}

export function validateReasonOptional(_: unknown, value: unknown, form: FormInstance): Promise<void> {
  const reasonSelect = value;
  const reasonText = form.getFieldValue("reasonText");
  const reason = composeReason(reasonSelect, reasonText);
  if (reason === null) return Promise.resolve();
  if (reason.length < REASON_MIN) {
    return Promise.reject(new Error(`操作原因至少 ${REASON_MIN} 个字符`));
  }
  if (reason.length > REASON_MAX) {
    return Promise.reject(new Error(`操作原因不超过 ${REASON_MAX} 个字符`));
  }
  return Promise.resolve();
}

export function validateReasonRequired(_: unknown, value: unknown, form: FormInstance): Promise<void> {
  const reasonSelect = value;
  const reasonText = form.getFieldValue("reasonText");
  const reason = composeReason(reasonSelect, reasonText);
  if (reason === null || reason.length === 0) {
    return Promise.reject(new Error("请选择或输入操作原因"));
  }
  if (reason.length < REASON_MIN) {
    return Promise.reject(new Error(`操作原因至少 ${REASON_MIN} 个字符`));
  }
  if (reason.length > REASON_MAX) {
    return Promise.reject(new Error(`操作原因不超过 ${REASON_MAX} 个字符`));
  }
  return Promise.resolve();
}
```

注: `import type { FormInstance } from "antd"` 加到 constants.ts 顶部 import 区(line 1 之前),`FormInstance` 是 type-only import 不影响运行时。

**acceptance_criteria:**

- `constants.ts` 文件末尾追加导出 `composeReason` / `validateReasonOptional` / `validateReasonRequired` 三个 helper + `REASON_CUSTOM_SENTINEL` 常量
- `validateReasonOptional` 与 `validateReasonRequired` 第三个参数为 `form: FormInstance`,从 `form.getFieldValue("reasonText")` 读取跨字段值
- 文件 line 数 ≥ 现有 69 行,新增内容在 `DESCRIPTION_MAX` 之后
