```
1. nil resp                          → WriteErrorTransport("nil response")
2. resp.Failed == true               → WriteErrorTransport(resp.Result)

4. rejectionMarkers 命中（含 "% Error:"）→ WriteErrorDeviceRejected

6. 默认                              → nil
```
