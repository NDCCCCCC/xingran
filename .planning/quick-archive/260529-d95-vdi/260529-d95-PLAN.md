<objective>
Add a "resource" dropdown selector to the VDI virtual machine creation form. When a user selects a resource group, the form fetches and displays the individual resources under that group via a cascading dropdown. The resource dropdown defaults to selecting the first option automatically.

Purpose: The current form only lets users pick a resource group, but VDI VM creation requires selecting a specific resource (compute resource) within that group. This cascading selection provides the correct granularity for VM creation.

Output: Working resource dropdown in the create VM form, backed by a new backend endpoint that proxies the VDI API `ListResources` call.
</objective>
