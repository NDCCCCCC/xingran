# 修复用户编辑模态框角色不显示

## 问题描述

用户编辑时，模态框中的角色选择器没有显示已选角色。

## 根本原因

- 后端返回的用户数据包含 `Roles`（角色名称数组），但缺少 `RoleIds`（角色ID数组）
- 前端表单使用 `roleIds` 字段来回显已选角色
- 数据不匹配导致无法显示

## 技术方案

### 后端修改

1. **修改 `List` 方法**：在填充角色名称时，同时填充角色ID数组到 `RoleIds` 字段
2. **修改 `GetByID` 方法**：添加角色关联数据加载，填充 `RoleIds` 字段

### 实施步骤

1. 修改 `user_service.go` 的 `List` 方法，在填充 `Roles` 时同时填充 `RoleIds`
2. 修改 `user_service.go` 的 `GetByID` 方法，添加角色数据加载
3. 测试验证

## 约束条件

- 保持向后兼容性
- 不影响现有 API 契约
- 遵循项目 Handler-Service 模式
