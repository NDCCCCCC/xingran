- **问题 ①（阻断，500）**：`internal/services/operations/workstation_service.go:16` 的 `workstationJoinSelect` 子查询把 `sys_workstation.id`（uuid）强制 `::text` 后去匹配 `ops_workstation_device.workstation_id`（uuid 列），导致 PostgreSQL 报错 `operator does not exist: uuid = text` (SQLSTATE 42883)，`workstation/list` 接口 500。修复为去掉多余 cast，使比较为 uuid = uuid。

## 问题 ① 关键类型证据
- `internal/models/workstation_device.go:20`：`WorkstationID string gorm:"type:uuid;not null;index:idx_workstation_device_workstation,priority:1"`
- `sys_workstation.id` 来自 `models.BaseModel.ID`，同样是 uuid 列。
- 因此子查询 `WHERE workstation_id = sys_workstation.id::text` 是 uuid 列与 text 字面量比较，触发 PG 42883。
- 同文件 `workstationJoinClause`（第 17 行）中的 `sys_dept.id::text = sys_workstation.dept_id` 与 `sys_user.id::text = sys_workstation.user_id` 是正确的，因为 `dept_id` / `user_id` 是 text 列；本题只需要去掉 `workstation_id = sys_workstation.id` 后的 `::text`。
