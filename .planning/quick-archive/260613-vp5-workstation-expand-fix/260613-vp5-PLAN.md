# 工位管理页面：恢复单元格点击展开/收起子表格 + 修复事件冒泡

## 目标

在工位管理页面（`xingran-react-frontend/src/pages/operations/workstations/index.tsx`）恢复"点击『查看设备/收起设备』所在单元格任意位置自动展开/关闭子表格"的行为，同时修复点击单元格内按钮时事件冒泡导致再次触发展开/收起的 bug。

## 当前实现（问题代码）

文件：`xingran-react-frontend/src/pages/operations/workstations/index.tsx`，行 408–426。

```tsx
expandable={{
  expandedRowRender: (record: WorkstationOps) => (
    <WorkstationDeviceTable
      workstationId={record.id}
      onDeviceChange={refreshData}
    />
  ),
  rowExpandable: () => true,
  expandIcon: ({ expanded, onExpand, record }) => (
    <Button
      type="text"
      size="small"
      onClick={(e) => onExpand(record, e)}
      style={{ fontSize: '12px' }}
    >
      {expanded ? '收起设备' : '查看设备'}
    </Button>
  ),
}}
```

问题：
1. 只有点击按钮本体才能展开/收起，单元格其余空白区域无响应。
2. 如果将来在单元格内增加额外按钮，点击按钮会冒泡触发整行 onClick。

## 目标实现

将 `expandIcon` 的渲染从裸 `<Button>` 改为可点击的 `<div>` 容器，容器 `onClick` 触发 `onExpand`，内部 `<Button>` 在 `onClick` 中先 `stopPropagation()` 防止冒泡二次触发。

```tsx
expandIcon: ({ expanded, onExpand, record }) => (
  <div
    role="button"
    tabIndex={0}
    onClick={(e) => onExpand(record, e)}
    onKeyDown={(e) => {
      if (e.key === 'Enter' || e.key === ' ') {
        e.preventDefault();
        onExpand(record, e as unknown as React.MouseEvent<HTMLElement>);
      }
    }}
    style={{ cursor: 'pointer', display: 'inline-block' }}
  >
    <Button
      type="text"
      size="small"
      onClick={(e) => {
        e.stopPropagation();
        onExpand(record, e);
      }}
      style={{ fontSize: '12px' }}
    >
      {expanded ? '收起设备' : '查看设备'}
    </Button>
  </div>
),
```

要点：
- 容器 div 接收 `onClick`，整单元格可点击切换。
- 容器添加 `role="button"` + `tabIndex={0}` + `onKeyDown`，保证键盘可达性（Enter / Space 等同点击），符合项目 Vercel React 最佳实践的可访问性要求。
- 内部 `<Button>` 在 `onClick` 中先 `e.stopPropagation()` 再调用 `onExpand`，避免事件冒泡到容器后再次切换状态（一次点击 = 一次切换）。
- 由于 Ant Design 的 `expandIcon` 渲染位置在每行最左侧展开列单元格内，按钮本身的 `e.nativeEvent.stopPropagation?.()` 也会阻止冒泡到行 `onRow.click`（当前表未设置 `onRow`，无需额外处理）。

## 风险与回滚

- **风险 1**：若容器 div 的 `onClick` 与 Ant Design `Table` 内部行点击事件冲突，可临时改用 `onMouseDown` 替代 `onClick` 验证，但当前项目 `<Table>` 未注册 `onRow`，无冲突。
- **风险 2**：若 `e.stopPropagation()` 阻止了 Ant Design 内部对 `expandIcon` 的处理（例如阻止了 `expandedRowRender` 的渲染），则改用 `e.nativeEvent.stopImmediatePropagation?.()` 或在按钮 onClick 中仅调用 `onExpand(record, e)` 而不调用 `stopPropagation`（此时依赖容器 div 的点击区域避免误点——这种情况下将按钮 `pointer-events: none`）。
- **回滚方案**：如方案 A 整体无法满足预期，回退到原始方案（裸 Button + 容器 div），仅保留"单元格空白处可点击"行为，并在按钮 onClick 中调 `e.stopPropagation()`。如仍有问题，git revert 本次提交。
