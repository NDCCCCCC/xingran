## 并行隔离机制（关键）

**GSD 本身无跨 phase 并行能力**（`parallelization: false`，且同 wave 内 `files_modified` 任一重叠即整波降级串行）。因此 W1/W2 的并行由**操作层实现**：

1. 每个并行卡片被执行器开在**独立 git worktree**（`git worktree add -b gsd/phase-XXX ../wt-XXX HEAD`），从同一个 main HEAD 起跑。
2. 每张卡片的任务描述里内嵌了**文件级归属协议**（见 `261123-v156-phase-parallelism.md` 第 3 节的 7 条），执行器只能写自己的文件集。
3. 执行器完成后在 worktree 内 commit，**不 merge**；由 Lead（主会话）按波次顺序 `git merge` 并跑全量闸门。
4. 若两个并行执行器越界写了同一文件 → Lead merge 时必然冲突 → 按归属协议判定谁对该文件有主权，另一方改动回退重做。
