<action>
创建 useWebSocket Hook，实现 WebSocket 连接管理。

实现要点：
1. 导出接口类型：
   ```typescript
   interface UseWebSocketOptions {
     url: string;
     onMessage: (data: unknown) => void;
     onOpen?: () => void;
     onClose?: () => void;
     onError?: (error: Event) => void;
     reconnect?: boolean;
     reconnectInterval?: number;
     maxReconnectAttempts?: number;
   }
   
   interface UseWebSocketReturn {
     status: 'connecting' | 'connected' | 'disconnected' | 'error';
     connect: () => void;
     disconnect: () => void;
     send: (data: unknown) => void;
   }
   ```
2. 使用 useState 管理 status 状态
3. 使用 useRef 存储 WebSocket 实例、重连次数、重连定时器
4. 实现 connect 方法：
   - 创建 WebSocket 实例：new WebSocket(url)
   - 设置 onopen、onmessage、onclose、onerror 回调
   - onopen 时设置 status='connected'，重置重连次数
   - onmessage 时解析 JSON 并调用 onMessage 回调
   - onclose 时设置 status='disconnected'，触发自动重连
   - onerror 时设置 status='error'
5. 实现指数退避重连逻辑：
   - 重连延迟 = reconnectInterval * Math.pow(2, attempts)
   - 最大延迟 30 秒
   - 重连次数不超过 maxReconnectAttempts
6. 实现 disconnect 方法：关闭连接、清理定时器
7. 实现 send 方法：发送 JSON 数据
8. 在 useEffect 清理函数中调用 disconnect

使用 export function useWebSocket(options: UseWebSocketOptions): UseWebSocketReturn 导出。
</action>
