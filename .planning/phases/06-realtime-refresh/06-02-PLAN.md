<action>
创建 useWidgetPolling Hook，实现数据轮询和缓存策略。

实现要点：
1. 导出接口类型：
   ```typescript
   interface UseWidgetPollingOptions {
     widgetIds: string[];
     interval: number; // 秒
     enabled?: boolean;
   }
   
   interface UseWidgetPollingReturn {
     loading: boolean;
     refresh: () => Promise<void>;
   }
   ```
2. 从 dashboardStore 获取：cacheWidgetData, getCachedWidgetData
3. 使用 useState 管理 loading 状态
4. 使用 useRef 存储 interval 定时器
5. 实现 fetchData 方法：
   - 检查缓存：遍历 widgetIds，跳过未过期的缓存
   - 缓存过期时间 = Math.max(interval / 2, 30) * 1000 毫秒
   - 只请求未缓存的 widget
   - 调用 dashboardService.getBatchWidgetData
   - 更新缓存：cacheWidgetData(id, data)
6. 使用 useEffect 设置轮询：
   - 首次加载：fetchData()
   - 设置定时器：setInterval(fetchData, interval * 1000)
   - 清理函数：clearInterval
7. 使用 useEffect 实现 Page Visibility API：
   - 监听 visibilitychange 事件
   - document.hidden 时暂停轮询（clearInterval）
   - !document.hidden 时恢复轮询（fetchData + setInterval）
8. 返回 { loading, refresh: fetchData }

使用 export function useWidgetPolling(options: UseWidgetPollingOptions): UseWidgetPollingReturn 导出。
</action>
