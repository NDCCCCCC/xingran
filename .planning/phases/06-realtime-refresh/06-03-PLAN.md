<action>
集成 DashboardView 组件，使用实时数据订阅 Hooks。

修改要点：
1. 导入 Hooks：
   ```typescript
   import { useWebSocket } from '@/hooks/useWebSocket';
   import { useWidgetPolling } from '@/hooks/useWidgetPolling';
   import { useNetworkStatus } from '@/hooks/useNetworkStatus';
   ```
2. 在组件中使用 useNetworkStatus：
   ```typescript
   const { isOnline, wasOffline, resetWasOffline } = useNetworkStatus();
   ```
3. 在组件中使用 useWidgetPolling：
   ```typescript
   const widgetIds = currentDashboard?.layout.widgets.map(w => w.id) || [];
   const { loading, refresh } = useWidgetPolling({
     widgetIds,
     interval: currentDashboard?.refreshInterval || 300,
     enabled: isOnline && viewMode === 'view',
   });
   ```
4. 在组件中使用 useWebSocket（如果仪表盘有 WebSocket 数据源）：
   ```typescript
   const { status: wsStatus, connect, disconnect } = useWebSocket({
     url: `/ws/dashboard/${currentDashboard?.id}`,
     onMessage: (data) => {
       // 处理推送数据，更新 store
       if (data.widgetId && data.data) {
         updateWidgetData(data.widgetId, data.data);
       }
     },
     reconnect: true,
   });
   ```
5. 添加网络状态提示：
   - 使用 Ant Design message 或 notification 显示离线/恢复提示
   - wasOffline 为 true 时显示"网络已恢复"提示
   - isOnline 为 false 时显示"网络已断开"提示
6. 添加 WebSocket 状态指示器（可选）：
   - 在仪表盘标题栏显示连接状态图标
   - 连接中显示加载动画
   - 断开显示警告图标

确保组件在卸载时正确清理 WebSocket 连接。
</action>
