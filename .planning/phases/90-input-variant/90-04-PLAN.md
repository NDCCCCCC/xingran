# Plan 04 — W3 收口：矩阵终跑 + computed 六断言 + 巡检 + 终值快照 + 验收报告

## Context

Phase 90 的**硬判据**全部要在本 plan 一次性收口。与 89 的收口范式一致（89-04），本 plan **不改任何业务代码** —— 若本 plan 发现任何不达标项，**回退到 90-02 / 90-03 修**，不得在收口波次里新开改动面。

三条与 89 不同的收口口径（90 特有）：

1. **矩阵是明暗双向的**（圆角 6→8 在 light/dark 都变）→ 89 的「light 差异必须 = 0」红线**不适用**于 90；90 的红线是「**light 与 dark 各自差异 > 0（防空跑）且全部归类，未归类 = 0，且形态集合与登记不多不少**」。
2. **M13 是本 phase 的核心量化目标**：InputNumber 错误态 `rgb(219,215,206)` → `rgb(186,54,48)`（明暗双测）。
3. **M15 从「6px/8px 混合」收敛到「输入类 + 分页器 = 8px」**，且**六处非输入域 6px 保持不变并已登记**（不得为了让数字好看而越界改动）。
