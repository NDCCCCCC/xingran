# Plan 03 — W2 评估收尾：R1-R5 保留论证 + T4 裁定 + 圆角归属 + 91/92 续办清单

## Context

Phase 90 的**主责**（批次 C/B、VISFIX-05、STYLE-03 圆角）在 90-02 落地；本 plan 是**评估与登记**波次，把「有意保留」的每一项论证、每一条债、每一个归属写清楚，避免 Phase 91/92 重新踩坑。

三条硬事实（执行时先复述再动手）：

1. **R1-R5 大部分是有意保留，不是漏做**。保留的判据是**色值等价性**：项目手写变量与 antd token **逐值相等**才可交还，不等价的必须先对齐 token 再删规则。
2. **T4（删 `font-size: 14px !important`）的裁定依据已经具备**：全仓 `size="large"` grep 命中 45 处，**没有一处是普通 `<Input size="large">`**；真正相关的只有 2 处 antd `Input.Search`（wrapper 结构，字号已被 VIS-01 复位块的 `font-size: inherit !important` 接管）+ 1 处 `<Form size="large">`（登录页，字号由 `login.css` 的 K10 复位块接管）→ **预期零视觉差异**，但仍须实测裁定。
3. **圆角归属有两张清单必须落盘**：六处字面 `6px`（Tag 域 5 处 + Tree 域 1 处）与 `--theme-radius-md` 的 **13 处**非输入域消费（研究 §B-6 记为「10 处」，**以实测 13 处为准**逐处登记）。
