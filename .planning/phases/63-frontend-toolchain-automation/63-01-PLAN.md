**Created:** 2026-08-14
**Source:** React+TS 自动化工作流评审的修正清单（评审发现原方案未核实仓库现状，本会话已逐条核实并修正）

## Goal

补齐前端工程化缺口：Prettier 实际落地（配置文件早已存在但工具未安装且配置与 ESLint 冲突）、git hooks、commit 规范、依赖自动更新、覆盖率阈值、死代码/体积监控。全部沿用现有配置风格，零业务代码改动。

## 关键事实核查结论（执行依据）

| 项 | 实际现状 | 执行决策 |
|---|---|---|
| Prettier | `.prettierrc` 存在但未装包；且 `singleQuote: true` 与 ESLint `quotes: ['error','double']` 及实际源码（双引号）冲突 | 装包 + 修 `singleQuote: false`，其余沿用 |
| CI | `.github/workflows/frontend-build.yml` 已存在（lint→type-check→test→build），但 node 22 与 CLAUDE.md "Node 24+" 不一致 | 只改 node 版本，不重建 CI |
| vitest | `vitest.config.ts` 已有 jsdom/globals/setupFiles/v8 | 仅增量加 thresholds，值以实测覆盖率为准 |
| hooks/commitlint/dependabot | 均无 | 按常规实践新增 |

## Tasks

1. **63-T1 Prettier**：`npm i -D prettier eslint-config-prettier` → 修 `.prettierrc`（singleQuote: false）→ eslint.config.js 末尾挂 `prettier` config → 加 `format`/`format:check` 脚本 → `prettier --write .` 一次性格式化 → **独立 commit**（格式化大 diff 与配置变更分离）
2. **63-T2 CI**：frontend-build.yml node-version 22 → 24
3. **63-T3 hooks**：husky + lint-staged + commitlint；`lint-staged.config.js` 用函数形式 `() => "npm run type-check"`（lint-staged 会追加文件列表，直接 `tsc --noEmit` 对子集文件无意义）；commit-msg 钩子接 commitlint conventional
4. **63-T4 Dependabot**：npm（/xingran-react-frontend，weekly，prod/dev 分组）+ github-actions（monthly）
5. **63-T5 coverage**：实测当前覆盖率 → thresholds 定为实测值下限（取整向下）合入现有 vitest.config.ts
6. **63-T6 advisory 工具**：knip（knip.json + `deadcode` script）+ size-limit（@size-limit/file + `.size-limit.json` + `size` script）；均 advisory，不进 CI gate

## Constraints

- 不换包管理器（保持 npm + package-lock.json，拒绝原方案的 pnpm 建议）
- 不装 Storybook / Chromatic（无独立组件库需求）
- 格式化 commit 与功能配置 commit 严格分离，保证 bisect 可用
- CI 不新增 format:check gate（本期只落地工具，gate 待团队适应后再开）

## Success Criteria

- SC#1: `npm run format:check` 通过；`npm run lint` 通过（eslint-config-prettier 无规则冲突）
- SC#2: `git commit` 触发 lint-staged（eslint --fix + prettier --write + type-check）与 commitlint
- SC#3: CI workflow 使用 Node 24
- SC#4: `npm run test:coverage` 通过且 thresholds 生效
- SC#5: `npm run deadcode` / `npm run size` 可运行（advisory）
