Wave 3 of operlog full coverage: instrument 63 write endpoints across the operations module (building / floor / workstation / workstation_device / server_room / room_device / dedicated_line / infopoint / wall / door / floor_plan_text / excel / asset). Excel import/export endpoints are highest-priority for audit ("who imported what batch of buildings last Tuesday?").

**WARNING 1 addressed (13 files exceeds 10-file threshold):** This plan deliberately keeps all 13 operations-module handler files in a single plan rather than splitting into 34-04a/04b/04c. Purpose: Operations is the most-bulk-edited module — Excel imports can create 1000+ workstations in one request. Without operlog coverage, an admin cannot tell who loaded which data set, and data-quality issues are untraceable. This wave delivers traceable bulk-edit history.
