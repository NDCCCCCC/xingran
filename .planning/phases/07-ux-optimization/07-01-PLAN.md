<action>
优化 DashboardGrid 组件，实现响应式布局。

实现要点：
1. 使用 react-grid-layout 的 Responsive 和 WidthProvider HOC：
   ```typescript
   import { Responsive, WidthProvider } from 'react-grid-layout';
   const ResponsiveGridLayout = WidthProvider(Responsive);
   ```
2. 定义响应式断点：
   ```typescript
   const breakpoints = { lg: 1200, md: 996, sm: 768, xs: 480, xxs: 0 };
   const cols = { lg: 24, md: 12, sm: 8, xs: 4, xxs: 2 };
   ```
3. 配置拖拽和调整大小：
   - draggableHandle: 指定拖拽手柄选择器
   - preventCollision: true 防止重叠
   - compactType: 'vertical' 垂直紧凑布局
   - margin: [16, 16] 网格间距
4. 添加动画过渡：
   - 使用 CSS transition 实现平滑动画
   - 拖拽时显示网格线辅助对齐
5. 处理布局变化：
   - onLayoutChange 回调更新 store
   - 保存布局到后端

确保移动端禁用拖拽功能。
</action>
