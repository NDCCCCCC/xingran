## D-102-5① TTL 锁定机制披露（仿 D-102-1 修订披露格式，向用户显式披露）

- **字面要求**: D-102-5①「键值等价测试（常量值 == 原字面量快照，**含 TTL 不变断言**）」；CONTEXT Deferred 亦写「TTL 值保持逐处等价并在等价测试中锁定」。
- **实际兑现**: 等价测试仅锁 6 个键格式值（TTL 不入常量——TTL 仍是调用点内联字面量，其常量化是 CONTEXT Deferred 明文不做）。**TTL 不变改以两道机制锁定，替代测试级断言**：① Task 2/3 acceptance 的 `git diff 无 time.Duration / Expire 行变更` 硬门（TTL 行零 diff）；② 既有回归测试网（captcha_78_01_test.go / captcha_background_78_01_test.go / core_74_08_test.go 内嵌键字面量与行为断言，TTL 漂移即红）。
- **理由**: 测试级 TTL 断言需引入 mock cache 捕获 Set 实参——为 Deferred 域新增测试装置违背 SP-1 最小 diff；「diff 零 TTL 行变更 + 回归网」对 TTL 漂移的检出能力与测试断言等价、成本更低。
- **影响**: 零行为影响。若用户坚持测试级 TTL 断言（mock cache 断言 Set 实参），execute 前提出即可升级本 plan。
