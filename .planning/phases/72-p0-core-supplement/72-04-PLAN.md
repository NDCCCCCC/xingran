The pattern (per D-01 service 范本 — READ port_write_service_test.go for actual implementation):
- Declare a mock struct that embeds `mock.Mock` (e.g. `type mockDB struct { mock.Mock }`).
- Implement each interface method as: capture `args := m.Called(ctx, params)` and return `args.Get(0).(T1), args.Get(1).(T2), args.Error(2)`.
- In each test: `db := new(mockDB); db.On("MethodName", mock.Anything, mock.Anything).Return(canned1, canned2, nil)` to set expectations.
- Construct the service via `NewWorkOrderCacheService(db, nil, nil)` (or appropriate constructor).
- Call the service method under test.
- Assert return values via `assert.NoError`, `assert.Equal`.
- Verify all expectations met: `db.AssertExpectations(t)`.
