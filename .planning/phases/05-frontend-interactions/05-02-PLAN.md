创建 DashboardSettings 组件，实现仪表盘设置编辑功能。

实现要点（per D-04, D-05 决策）：
1. 接收 props: `{ visible: boolean; onClose: () => void }`
2. 使用 Ant Design Drawer 组件：
   - placement="right"（per D-04）
   - width=480
   - title="仪表盘设置"
3. 从 dashboardStore 获取 currentDashboard
4. 使用 Form 组件绑定表单：
   - name: Input, rules: [{ required: true, message: '请输入名称' }]
   - description: Input.TextArea, rows=3
   - scope/deptId/isSystem: 使用 DashboardScopeSelector 组件（per D-05）
   - refreshInterval: 使用 RefreshIntervalSelector 组件
5. 实现 handleSave 函数：
   ```tsx
   const handleSave = async () => {
     const values = await form.validateFields();
     await updateDashboard(currentDashboard.id, {
       name: values.name,
       description: values.description,
       scope: values.scopeConfig.scope,
       deptId: values.scopeConfig.deptId,
       isSystem: values.scopeConfig.isSystem,
       refreshInterval: values.refreshInterval,
     });
     onClose();
   };
   ```
6. Drawer footer 包含"取消"和"保存"按钮，保存按钮设置 loading 状态
7. visible 变化时初始化表单值：form.setFieldsValue(currentDashboard)

使用 useState 管理 loading 状态，保存时禁用按钮防止重复提交。
</action>
