创建 TemplatePreview 组件，实现模板全屏预览功能。

实现要点（per D-07, D-08, D-09 决策）：
1. 接收 props: `{ visible: boolean; template: Dashboard | null; onClose: () => void; onApply: (templateId: string, name: string) => void }`
2. 使用 Ant Design Modal 组件实现全屏覆盖：
   ```tsx
   <Modal
     open={visible}
     onCancel={onClose}
     footer={null}
     width="100vw"
     style={{ top: 0, paddingBottom: 0 }}
     bodyStyle={{ height: 'calc(100vh - 110px)', overflow: 'auto' }}
   >
   ```
3. 使用 useState 管理 previewData: `Map<string, unknown>` 和 loading 状态
4. 实现 loadPreviewData 函数获取真实数据（per D-08）：
   ```tsx
   const loadPreviewData = async () => {
     if (!template) return;
     setLoading(true);
     try {
       const widgetIds = template.layout.widgets.map(w => w.id);
       const data = await dashboardService.getBatchWidgetData(widgetIds);
       setPreviewData(data);
     } catch (error) {
       message.error('加载预览数据失败');
     } finally {
       setLoading(false);
     }
   };
   ```
5. 使用 useEffect 在 visible 变化时调用 loadPreviewData
6. 渲染 DashboardGrid 组件显示模板布局，传入 previewData
7. 底部固定显示操作按钮：
   ```tsx
   <div style={{ position: 'fixed', bottom: 24, right: 24 }}>
     <Button onClick={onClose}>取消</Button>
     <Button type="primary" onClick={() => onApply(template.id, `${template.name} - 副本`)}>
       使用此模板
     </Button>
   </div>
   ```
8. 使用 Spin 组件包裹内容，显示 loading 状态

失败时显示错误提示，不缓存预览数据（per RESEARCH.md Open Questions）。
</action>
