1. 接收 props: `{ value: DataSourceConfig; onChange: (value: DataSourceConfig) => void; widgetType: WidgetType; form: FormInstance }`
2. 使用 Select 组件选择数据源类型，选项根据 widgetRegistry[widgetType].supportedDataSources 过滤

   - channel: Input (WebSocket 频道)
   - transform.expression: Input
6. Static 类型表单字段：
   - data: Input.TextArea (JSON 格式)

使用 Ant Design Form.Item 包裹每个字段，设置 rules: [{ required: true }] 验证必填项。
</action>
