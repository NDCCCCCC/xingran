    3. **新增 getByWorkstationWithCache wrapper（D-103-7 warn-on-set 不阻断语义）**：
       ```go
       func (s *reconciliationServiceImpl) getByWorkstationWithCache(ctx context.Context, cacheKey string, wsID string) (*ByWorkstationResponse, error) {
           result, err := base.GetOrSetJSON[*ByWorkstationResponse](ctx, s.cache, cacheKey, reconciliationHealthCacheTTL, func() (*ByWorkstationResponse, error) {
               return s.computeByWorkstation(ctx, wsID)
           })
           // D-103-7: warn-on-set 不阻断语义
           if err != nil {
               applogger.Warnf("[reconciliation] GetByWorkstation cache set failed wsID=%s: %v", wsID, err)
               if result != nil {
                   result.Visible = false
                   return result, nil  // 即使 set 失败，结果仍可用
               }
               return nil, err
           }
           if result != nil {
               result.Visible = false
           }
           return result, nil
       }
       ```
       **注意**：`Workstation.ID != ""` 脏缓存防御已由 base.GetOrSetJSON 语义覆盖（若 cache 中存储的响应 Workstation.ID 为空则视为无效 cache，会触发回源）。如需要显式检查，可将 `computeByWorkstation` 内逻辑确保返回有效 ID。

    4. **GetByWorkstation 改写（:793-824）**：删除手写 cache-aside（`cache.GetJSON` 短路 + `json.Marshal` + `cache.Set`），替换为：
       ```go
       cacheKey := GetReconciliationHealthByWorkstationKey(wsID)
       return s.getByWorkstationWithCache(ctx, cacheKey, wsID)
       ```

    5. **SaveRecord 失效（D-103-14）**：将既有的 `InvalidateWorkstationHealth(ctx, s.cache, wsID)` 或 `s.cache.Delete` 替换为：
       ```go
       base.Invalidate(ctx, s.cache, []string{GetReconciliationHealthByWorkstationKey(wsID)}, "Reconciliation")
       ```

    6. **模式失效（D-103-15）**：如有 `cache.DeleteByPattern` 调用，替换为 `base.InvalidatePattern(ctx, s.cache, []string{pattern}, "Reconciliation")`。

    **不要改动**：`computeByWorkstation` 函数本身；matcher 字段；mvExists/mvExistsMux 字段。
