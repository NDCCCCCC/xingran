## Phase 22A: VDI 基础集成

**目标**: 完成深信服 VDI 平台的基础集成，实现虚拟机的完整生命周期管理

**包含 Waves**:
- Wave 1 (22-01): 数据模型与配置基础
- Wave 2 (22-02): VDI API 客户端与认证
- Wave 3 (22-03): VDI 服务层实现
- Wave 4 (22-04): VDI 后端 API 层
- Wave 5 (22-05): VDI 前端 UI 实现

**工作量**: 12-15 小时（2 个工作日）

**依赖**: 无（独立功能）

**交付物**:
- ✅ 4 个数据表（sys_vdi_vm, sys_vdi_server, sys_vdi_resource_group, sys_vdi_user_binding）
- ✅ VDI API 客户端（认证 + 所有 VDI API 调用）
- ✅ 完整的服务层实现
- ✅ 17 个后端 API 端点
- ✅ 前端虚拟机管理页面

**成功标准**:
1. ✅ 可配置多个 VDI 服务器
2. ✅ 可从 VDI 同步虚拟机列表
3. ✅ 可对虚拟机进行开关机、重启、删除操作
4. ✅ 可配置虚拟机 IP 地址
5. ✅ 可绑定/解绑用户
6. ✅ 前端可管理所有 VDI 资源

**优点**:
- 🎯 独立可用的完整功能
- 🎯 可以立即交付使用
- 🎯 为后续功能奠定基础

---

## Phase 22B: VM Agent 服务

**目标**: 实现部署在虚拟机内的 Agent 服务，支持账号管理和终端访问

**包含 Waves**:
- Wave 6 (22-06): VM Agent 服务实现

**工作量**: 6-8 小时（1 个工作日）

**依赖**:
- Phase 22A（需要 VM 数据模型）

**交付物**:
- ✅ Agent 服务（支持 Windows + Linux）
- ✅ JWT 认证和令牌刷新
- ✅ 跨平台账号操作（创建、删除、启用、禁用）
- ✅ 伪终端管理（PTY）
- ✅ 心跳上报机制
- ✅ 安装脚本（PowerShell + Bash）

**成功标准**:
1. ✅ Agent 可在 Windows/Linux 上部署
2. ✅ Agent 可向后端注册并获取 JWT 令牌
3. ✅ Agent 可执行账号 CRUD 操作
4. ✅ Agent 定期发送心跳
5. ✅ 后端可调用 Agent API

**优点**:
- 🎯 独立的 Agent 服务，可单独开发和测试
- 🎯 跨平台编译，支持批量部署
- 🎯 为账号管理提供基础设施

## Phase 22C: 账号管理与密码

**目标**: 实现虚拟机内账号的完整管理功能和自动密码轮换

**包含 Waves**:
- Wave 7 (22-07): 账号管理后端
- Wave 8 (22-08): 密码轮换系统

**工作量**: 7-9 小时（1-1.5 个工作日）

**依赖**:
- Phase 22A（VM 数据模型）
- Phase 22B（Agent 服务）

**交付物**:
- ✅ 3 个数据表（vdi_vm_accounts, vdi_agents, vdi_audit_logs）
- ✅ 账号管理后端 API（7 个端点）
- ✅ Agent 通信层（HTTPS + JWT）
- ✅ 密码轮换调度任务
- ✅ 密码历史记录
- ✅ 密码策略配置

**成功标准**:
1. ✅ 可管理 VM 内的账号（CRUD）
2. ✅ 可重置账号密码
3. ✅ 系统可自动轮换密码（默认 90 天）
4. ✅ 密码历史记录防止重复使用
5. ✅ 所有操作记录到审计日志

**优点**:
- 🎯 完整的账号生命周期管理
- 🎯 自动密码轮换，满足安全要求
- 🎯 完整的审计日志

- **22C**: 完整的账号管理
- **22D**: Web 终端和审计

- **22B 失败**: 仍可使用 SSH/WinRM 方案（22A 已完成）
- **22C 延期**: 不影响基础的 VDI 管理功能
- **22D 暂缓**: 核心功能已可用
