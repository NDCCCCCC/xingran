  <action>
Modify `ruoyi-react-frontend/vite.config.ts`:

1. Add at top of file (after existing imports, after the path import):
   `import { visualizer } from 'rollup-plugin-visualizer';`

2. Replace the `plugins` array. Add a conditional visualizer that ONLY runs when env var `ANALYZE=true` is set (e.g. via `process.env.ANALYZE` check) so the default build is unaffected. Use the gzip/brotli size options and a treemap template:
   ```
   plugins: [
     react(),
     tailwindcss(),
     removeConsole(),
     ...(process.env.ANALYZE === 'true' ? [visualizer({
       filename: 'dist/stats.html',
       gzipSize: true,
       brotliSize: true,
       template: 'treemap',
     })] : []),
   ]
   ```

3. Rewrite `build.rollupOptions.output.manualChunks` to align with D-07 chunk-naming. Replace the existing inline-if-chain with a function so we have explicit control:
   - Return `'vendor-react'` for `react-dom`, `react-router`, `scheduler`, and any path containing `/react/` (but NOT `@react-three`, `@react-spring/three`, etc.). This means: match `/node_modules/react/`, `/node_modules/react-dom/`, `/node_modules/react-router/`, `/node_modules/scheduler/`, etc.
   - Return `'vendor-three'` for paths containing `three`, `@react-three`, `@react-spring/three`, `maath`. Note: `three` substring also matches `three-vendor` content from existing rule — but since this new function runs first, OK.
   - Return `'vendor-antd'` for paths containing `antd`, `@ant-design`, or `/rc-` (rc-* utility packages AntD depends on).
   - Return `'vendor-echarts'` for paths containing `echarts` or `zrender`.
   - Return `'vendor-utils'` for paths containing `dayjs`, `axios`, or `sm-crypto` (D-06: keep sm-crypto sync).
   - Return `'vendor-commons'` for everything else in `node_modules`.
   - Return `undefined` for first-party code (so they stay as route-level chunks).

   Concretely:
   ```
   manualChunks(id) {
     if (!id.includes('node_modules')) return undefined;
     if (id.includes('three') || id.includes('@react-three') || id.includes('@react-spring/three') || id.includes('maath')) return 'vendor-three';
     if (id.includes('echarts') || id.includes('zrender')) return 'vendor-echarts';
     if (id.includes('antd') || id.includes('@ant-design') || id.includes('/rc-')) return 'vendor-antd';
     if (id.includes('/react-dom/') || id.includes('/react-router') || id.includes('/scheduler/') || (id.includes('/react/') && !id.includes('@react-'))) return 'vendor-react';
     if (id.includes('dayjs') || id.includes('axios') || id.includes('sm-crypto')) return 'vendor-utils';
     return 'vendor-commons';
   }
   ```
   Order matters: `vendor-three` and `vendor-react` checks use overlapping substrings — check three-family first so `@react-three/fiber` lands in `vendor-three`, then antd, then react core.

4. Set `chunkSizeWarningLimit: 500` (KB), per D-05 / D-07 — the 500KB gzip budget.

5. Keep `optimizeDeps.include` unchanged (sm-crypto and react must keep ESM compatibility).

6. Keep the `server.proxy` and `server.port: 4000` configuration unchanged.

After editing, the file must remain a valid ESM module exporting `defineConfig({...})`.
