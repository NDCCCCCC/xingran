# Plan 23-08: Add Member OU DN Configuration Field

## Objective
Add `member_ou_dn` field to ADConfig model and database to support specifying the target OU for department groups (e.g., "本部部门分组"). This enables the system to know where to create and manage department-based AD groups.

**Purpose**: Enable configuration-based specification of where department groups should be created/managed in AD, removing hardcoded OU references.

**Output**: ADConfig model with MemberOUDN field, database migration adding the column.
