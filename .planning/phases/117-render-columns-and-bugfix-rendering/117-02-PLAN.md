<objective>
RENDER-02：5+ 大数据页补 Table `virtual` + `scroll.y`，实现虚拟滚动提升大数据量渲染性能。

Purpose: 大数据量表格（1000+ 行）渲染时 DOM 节点过多导致滚动卡顿；Ant Design Table 的 virtual 模式只渲染可见行，scroll.y 设置可视区域高度，两者配合实现流畅滚动。对照 assets:716 等 4 个已启用页面的既有模式。
Output: 5 页 Table 启用虚拟滚动，既有功能零回归。
</objective>
