## Phase 70 布局与交互契约（下游 planner / executor 直接施工依据）

### L-1 SettingsShell（D-01 / D-03 / D-04 / D-05）

**归属目录裁定**：`xingran-react-frontend/src/design-system/components/SettingsShell.tsx` —— 与 LayoutSwitcher / DensitySwitcher 同级，理由：跨两页共用骨架 + 纯令牌消费性质（RESEARCH Open Question 2 采纳其建议）。

**结构**：分类注册表驱动（模块级常量或 useMemo，CLAUDE.md useEffect 纪律）：

```tsx
interface SettingsCategory {
  key: string;          // = URL 参数值
  label: string;
  icon: ReactNode;
  content: ReactNode;
  maxWidth?: number;    // 表单类限宽，表格类缺省撑满（D-02）
}
```

**分类注册表（本 phase 全量）**：

| 页面 | 路由 | cat 值 | label | icon | 宽度策略 |
|------|------|--------|-------|------|---------|
| 系统设置 | `/system/settings-page` | `email`（默认） | 邮箱配置 | MailOutlined | 撑满（表格） |
| | | `api` | API配置 | ApiOutlined | 撑满（表格） |
| | | `captcha` | 验证码背景图 | PictureOutlined | 撑满（网格墙） |
| 用户设置 | `/user/settings` | `appearance`（默认） | 界面设置 | BgColorsOutlined | 限宽 760px |
| | | `layout` | 布局设置 | LayoutOutlined | 限宽 760px |
| | | `data` | 数据设置 | DatabaseOutlined | 限宽 760px |

- **URL 参数名裁定：`cat`**（CONTEXT D-03 示例 + RESEARCH Pattern 2 一致，短且语义明确）。参数挂真实路径（RESEARCH 关键推论：CONTEXT 中 `/system/settings?cat=email` 为示意，实际为 `/system/settings-page?cat=email`）。
- 激活态：`useSearchParams` 为唯一真相源；非法/缺失 `cat` 回退默认值；切换用 `setSearchParams({ cat: key }, { replace: true })`（不污染 history 栈、不产生新 RouteTab——tab key = pathname，Pitfall 3 已验证）。
- **桌面端（≥lg，`Grid.useBreakpoint()`）**：`Layout` + `Sider width={220}`（透明底）+ `Content`。左导航 = 白卡（`.xr-settings-nav`：surface 底 / 1px border-primary / radius-xl / padding 12px），内含分类项列表。
- **窄屏（<lg）**：顶部 `<Segmented block>`（options = label+icon，value=activeCat，onChange=setCat；默认 size，antd 6 为 medium）+ 内容区全宽。
- 分类项（`.xr-settings-nav-item`）：全宽左对齐、padding `8px 12px`、圆角 `var(--theme-radius-md)` 6px、icon 16px + label 14px、gap 8px；默认文字 `var(--theme-text-primary)` icon `var(--theme-text-secondary)`；hover `var(--theme-primary-50)`；active `rgba(21,96,49,0.1)` 底 + primary 字 + 600。**必须为 button 元素并带 aria-current**（可达性）。
- 右内容卡（`.xr-settings-content`）：白卡同语汇，padding `var(--theme-spacing-xl)` 20px；表单类内容内部再包 `maxWidth: 760px` 容器。

### IC-1 用户设置保存交互裁定（RESEARCH Open Question 1）

**即改即存**：每行控件 onChange 直接调用 settingsStore 对应更新方法（`updateTheme` / `updateLayout` / `updateDataPageSize` 已具备单字段能力）+ `message.success("已保存")` 轻提示；**移除底部「保存设置 / 重置」按钮**（即改即存后「上次保存」即当前态，重置失去语义）。失败路径：`message.error("保存设置失败，请重试")` 且控件回滚到 store 当前值。理由：与 D-06 行式形态语义一致（行式 = 每行独立开关，现代 settings 惯例），消除「改了没保存」状态焦虑。planner 如评估后端 PUT /preferences 频率风险可回退为底部保存按钮（低频操作，预期无风险）。
