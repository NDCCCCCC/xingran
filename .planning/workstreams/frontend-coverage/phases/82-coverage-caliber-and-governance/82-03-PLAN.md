  1. `EMPTY=$(git hash-object -t tree /dev/null)` 取空树 SHA（即 4b825dc...）；`BASE=$(git commit-tree "$EMPTY" -m "phase-82 synthetic diff base")` 造一个悬空基准 commit——`diff BASE...HEAD` = 全部 src 文件所有行都是新增，join 后 diff coverage ≈ 全局语句覆盖比（约 3.85%）。悬空 commit 不建分支不 push，GC 自动回收。
  2. FAIL 分支：threshold 80 → 必须 exit 1，stdout 含 `FAIL: diff coverage` 且有 `UNCOVERED ` 行清单。
  3. PASS 分支：threshold 0 → 必须 exit 0，stdout 含 `PASS: diff coverage`，`DIFF <covered> <total> <pct>` 行 total > 0、covered > 0、pct 落在 (0,100)。
  4. 在 SUMMARY 记录 DIFF 行的 covered/total/pct 三个实测值（82-04/82-05 的 join 正确性参照基线）。
  </action>
