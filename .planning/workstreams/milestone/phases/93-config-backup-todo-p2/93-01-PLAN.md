4. 改造 createNewAutoBackup 的文件分支（现 :385-394）：与 CreateBackup 同构——文件名追加 .gz、gzipCompress 压缩后写入、`backup.Compressed = true`、BackupSize 保持 len(config)；错误返回 "压缩备份内容失败: %w"。
