# VDI 数据获取工具使用说明

## 快速开始

### Windows 用户

#### 方法 1：Python 脚本（推荐）

```cmd
python scripts/get_vdi_data.py
```

#### 方法 2：批处理脚本

```cmd
scripts\get_vdi_data.bat
```

### Linux/Mac 用户

#### 方法 1：Python 脚本（推荐）

```bash
python3 scripts/get_vdi_data.py
```

#### 方法 2：Shell 脚本

```bash
chmod +x scripts/get_vdi_data.sh
./scripts/get_vdi_data.sh
```

## 输入要求

- **VDI 服务器地址**：默认 `https://10.62.0.79:6060`
- **用户名**：默认 `admin`
- **密码**：运行时会提示输入

## 输出说明

脚本会显示：

1. **认证状态** - 是否成功登录
2. **资源组列表** - 所有资源组的信息
3. **虚拟机列表** - 每个资源组下的虚拟机（前 10 个）
4. **统计信息** - 总虚拟机数量

同时会生成以下 JSON 文件：

- `vdi_auth_response.json` - 认证响应
- `vdi_groups_response.json` - 资源组数据
- `vdi_all_vms.json` - 所有虚拟机数据

## 自定义配置

### 修改服务器地址

编辑脚本中的 `VDI_URL` 变量：

**Python 版本：**
```python
VDI_URL = "https://your-server:6060"
```

**批处理版本：**
```cmd
set VDI_URL=https://your-server:6060
```

**Shell 版本：**
```bash
VDI_URL="https://your-server:6060"
```

### 修改用户名

编辑脚本中的 `VDI_USERNAME` 变量。

## 故障排除

### 问题：认证失败

**解决方案：**
1. 检查用户名和密码是否正确
2. 确认 VDI 服务器地址正确
3. 检查网络连接

### 问题：资源组为空

**解决方案：**
1. 登录 VDI 管理界面确认有配置资源组
2. 检查资源组是否已启用

### 问题：找不到 Python

**Windows 解决方案：**
1. 下载并安装 Python: https://www.python.org/downloads/
2. 安装时勾选 "Add Python to PATH"

**Linux 解决方案：**
```bash
# Ubuntu/Debian
sudo apt-get install python3

# CentOS/RHEL
sudo yum install python3
```

## 注意事项

1. **密码安全**：脚本不会保存密码，仅在内存中使用
2. **HTTPS 证书**：脚本会跳过 SSL 证书验证（适用于自签名证书）
3. **网络要求**：需要能够访问 VDI 服务器的网络
