# 缓存键迁移快速指南

## 一分钟快速开始

### 1. 检查当前状态
```bash
cd scripts/migrate_cache_keys
make verify
```

### 2. 预览将要删除的旧键
```bash
make cleanup-dry
```

### 3. 执行清理（确认后）
```bash
make cleanup-force
```

### 4. 验证清理结果
```bash
make verify
```

## 迁移前后对比

| 项目 | 旧规范 | 新规范 |
|------|--------|--------|
| **键格式** | `user:id:uuid` | `cache:user:id:uuid` |
| **前缀** | 无 | `cache:` |
| **模块区分** | 弱 | 强 |
| **批量操作** | 困难 | 容易 |

## 影响范围

**自动生效（无需操作）：**
- ✅ 用户登录
- ✅ 权限加载
- ✅ 字典数据
- ✅ 部门树
- ✅ 菜单树

**需要手动清理：**
- ⚠️ Redis中的旧键（使用本工具）

## 常见问题

**Q: 会影响业务吗？**
A: 不会。新键自动创建，旧键自然过期。

**Q: 需要停机吗？**
A: 不需要。迁移过程完全在线进行。

**Q: 清理后能回滚吗？**
A: 不能。清理前请确认系统运行正常。
